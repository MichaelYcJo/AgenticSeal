## The replacement

A rule is stated once, in one home, and ends with `Enforced by:` naming what holds it: a test as pytest spells its node id, a unit (`path::name`), a file, or an eval case directory under `evals/behaviour/` (`<agent>/<case>/`, resolving where `case.yaml` is in it — the one grammar addition, because an agent's rule can be held by nothing else nameable). `nothing — <why>` stays allowed and is counted. CI running the suite is the check. Two rows in `seal/budgets.md`, measured by `budget_check.py` on every pull request and in the suite, hold the shape without a person:

1. **`enforced-unresolved`**, a `gate` row at ceiling 0: every `Enforced by:` target in every rule file resolves through `fold_check.py#target_problem` (which already calls `evidence_check.py#named_unit`), widened to the eval-case directory. A target that is gone, renamed, defined twice or a constant fails the run naming the file, the heading and the target. What it cannot read is stated: whether the test runs or is skipped on the sealing leg, and whether it asserts the rule (review is the reader of that).
2. **`unenforced:<file>`**, a `gate` family, two-sided at `+0`, one row per rule file at today's count: the number of rule paragraphs (bold-led, `**`, `- **`, `N. **`, outside fences, tables and comments — #923's reader) that carry no `Enforced by:` line or carry `nothing`. A new rule without a test raises the row and owes a `Budget raised:` line with its reason; a rule that gains its test lowers it in the same pull request. Today's counts seed the table: `docs/` 457 rule paragraphs against 199 `Enforced by:` lines (12 of them `nothing`); #923 measured 1,176 paragraphs over 68 files with 143 ending in `Enforced by:`.

The rule files are `docs/*.md`, `agents/*.md`, `skills/*/SKILL.md`, `skills/*/orchestration.md`, `templates/*.md`, `CONTRIBUTING.md`, `CLAUDE.md` — #923's set. A work item's own claims live in its `spec.md` scenario table, whose *Verifiable how* cell names the test; the fold writes the surviving rule into `docs/` with its `Enforced by:` line. No fragment, no row, no hash, no date. History lives in git, `changelog/`, and the work-item records.
