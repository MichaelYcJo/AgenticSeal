### Changed

- **Each shipped module's tests stand in one file that names it, grouped by function (#942).** A test file declares `TARGET`, the module it tests, as its first statement after the imports, and holds one class per public function of that module, with cases that accept beside cases that refuse. `bin/test-layout --check` refuses a class that names no function of its target, a function class without both kinds of case, and a helper defined byte-identically in two test files. `bin/test-layout --pairs` names two cases of one class that call the function with equal arguments, and exits 0. The commit flow and the creation flow, which run real git end to end, stand in `tests/e2e/commit/` and `tests/e2e/creation/`. 115 test files still declare no `TARGET`, each for a reason `overview.md` *Not done* names, so the suite case runs `--check` without `--all` until a later settle frees them.
- **A module whose cases were only moved is decided by a check, not by the record (#942).** `bin/test-layout --moved <base> --from <old files> --to <new files>` exits 0 only where every old case lands once, its body unchanged, its fixtures unchanged, and every name it and its fixtures read defined as the base defined it. It follows a name into another test file and into an import made inside a function body, and prints each failing case with every name it reads apart. Its four limits are stated in `skills/verify/scripts/test_layout.py`'s docstring. A group that passes skips the mutants; a group that fails runs them for each module its failing cases send.
- **A rebuilt module's proof is one batch of decision-point mutants (#942).** `bin/mutation-check <path> --tests <command> --replace OLD NEW`, with `--replace` given once per mutant, runs the baseline once and each mutant once, and prints one verdict line per pair. The old files run only for a survivor, so a mutant that survives both is recorded as a gap the old tests already had. The 174 such gaps are on #1017.
- **A slow case is reported, not failed (#942).** `tests/conftest.py#SLOW_CASE_S` names each case whose call runs past it in one line at the end of the run, and the run exits 0. The failing ceiling and its environment variable are gone.
- **A census runs with its module, and its exemptions sit beside the line they exempt (#942).** `tests/censuses.py` holds each census as a function, `tests/conftest.py#census_case` gives every module's file one case that runs them, and an exemption is a comment line directly above the exempted line. A comment above a line no census flags is refused, and the stored exemption lists are gone.
- **The release table has a row per test file (#942).** `release_report.py#module_rows` reads `.test_durations` at the tag and at the head and prints each file's cases and seconds at both.
- **The suite runs in half the time locally (#942).** `bin/test -q` took 183.9 s over 7,494 items at the base and 91.4 s over 7,726 at 6a54be98, on macOS.
