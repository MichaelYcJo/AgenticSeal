# Questions for the planner: 1792935671-the-routing-check-moves-to-the-sessions-tools

The judgments the issue left open that the tree answered, so nobody reopens them:

- **Whether the edit hook reaches a subagent's edits.** Assumed yes, and the build proceeds on it. A subagent's `Write` reaches `PostToolUse` with the main session's `session_id` (`hooks/sealer-stamp-queue.py` docstring, citing Q1 of work item 1792363231, measured 2026-10-19). A subagent's Bash call reaches `PreToolUse` (`docs/commit-review-gate-spec.md` *The PreToolUse reading of a commit*: *a subagent's call carries its parent's session id*). No case can run the harness, so Q3 measures it once, live.
- **Edits made through Bash.** No edit tool runs, so the edit hook never sees them. Two things answer for them: contract rule 9, which sends every agent's edit through the `Edit` tool and now gives the edit check as its reason, and the trailer arm at the pull request (`spec.md` *Rule changes*, `docs/the-routing-check.md`).
- **What the pull request reads where the trailer is absent.** Nothing: the commit is not judged. Only that reading never judges a teammate, which decision 4 and #952 step 4 both require. The cost is stated in the rule.
- **Which trailer.** SpecSeal's own `SpecSeal-Routing:`, not the harness's `Co-Authored-By:`. Every Claude Code session carries the second, a teammate's included (`plan.md` *Alternatives considered*).
- **Whether any job of git's hooks stays at git.** None does. Each has a session-side or pull-request home, enumerated by construction from `hooks/commitgate.py`, `hooks/gate.py#arms_missing` and `hooks/commit-review-gate.py#main` (`spec.md` *Data & interfaces*).
- **Whether `hooks/cmdline.py` goes.** No. The worktree guard, `hooks/tokens.py#without_bodies` and `hooks/implementer-notice.py` read it. Only the units that the commit gate alone reaches go.
- **What the edit check does not judge.** Files under the `seal/` root, so that the declaration can always be written. Ignored files, which never land in a commit. Files outside every opted-in repository.
- **A paused rebase.** The branch the rebase names stands for the detached HEAD, so resolving a conflict on a declared branch is never refused.
- **How the two retired documents leave `docs/`.** Phase 1 teaches `apply_op` that a removal naming nested headings removes the outer one. `spec.md`'s removal of `docs/the-commit-gate-inside-git.md` parses today and applies once phase 1 lands.
