### Removed

- **`/agentic:update` no longer takes a preset block out of `CLAUDE.md` (#1500).** Releases from 0.23.0 to 0.24.2 wrote a block into the user's `CLAUDE.md`, between `<!-- agentic:start -->` and `<!-- agentic:end -->`, and step 4 of `skills/update/SKILL.md` took it out after a backup. The step is gone, and so is `templates/setup/claude-md-block.md`, the empty marker pair the update to 0.25.0 copied. No step of the update opens a `CLAUDE.md` now.
- **`/agentic:update` no longer looks for the stamp launcher an earlier release wrote (#1500).** Releases from 0.33.0 to 0.34.1 drew the sealer's stamp through `${CLAUDE_PLUGIN_DATA}/stamp.py` and a `Stop` entry in the person's settings that ran it. Step 4b named both for the person to remove. The step is gone, and an update that is already current now says so and stops. The step that names `/reload-plugins` and a restart is now step 4.
- **`seal mode` no longer converts an earlier release's `seal/config.md`, and no command refuses one or a `seal/parity.md` (#1500).** Releases through 0.36.0 kept their settings in `seal/config.md`. Where no `seal/config.json` stood beside it, a command that read a setting through `lib/config.py` refused the file and named `seal mode`, which wrote `config.json` from the file's table and removed it. A root holding `config.md` and no `config.json` now declares nothing, as a root holding neither does, so every key reads as absent. Bare `seal mode` writes its `Mode` key into a new `config.json` and leaves `config.md` as it is. `chain-check` no longer refuses a pull request whose HEAD carries `seal/parity.md` without `seal/parity.json`, and `seal mode` no longer names that file. A `parity.md` alone is no migration config, so the parity arm reads nothing from it.
- The version moves to 0.38.1.

Updating: nothing to do if you are on 0.37.0 or later. On 0.36.x or earlier, do by hand what the removed paths did. Write `seal/config.json` from `templates/setup/config.md`, with the rows of `seal/config.md` as its keys, and delete `seal/config.md`, since no command reads that file and every key reads as absent until then. Where `seal/parity.md` stands, write `seal/parity.json` from `templates/setup/parity.json` and delete `seal/parity.md`, since the parity arm reads no `parity.md`. Move the `| Signer |` table of a `seal/pact.md` into a `Pact signers` key of that repository's `seal/config.json`, and `~/.claude/agentic/pact-paths.md` into `~/.claude/agentic/pact-paths.json`. Delete the lines between `<!-- agentic:start -->` and `<!-- agentic:end -->` in `~/.claude/CLAUDE.md`, the markers included, which a release from 0.23.0 to 0.24.2 wrote. Remove from `${CLAUDE_CONFIG_DIR:-$HOME/.claude}/settings.json` the `Stop` entry whose command runs `${CLAUDE_PLUGIN_DATA}/stamp.py`, then that file, which a release from 0.33.0 to 0.34.1 wrote.
