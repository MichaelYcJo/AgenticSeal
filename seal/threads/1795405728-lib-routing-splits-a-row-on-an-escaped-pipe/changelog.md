### Fixed

- **A `routing.md` cell holding an escaped pipe reads as the one cell GitHub renders (#1574).** `lib/routing.py#table_rows` split a row at every pipe. So a `Branch` row whose value was `fix/a\|b` read as `fix/a\`, and the rest of the cell was dropped. Every table row in `lib/` is now split by `lib/tables.py#table_cells`, the splitter held to cmark-gfm, and the routing reader, the closing memo reader `lib/gaps.py` and `seal fold`'s index reader read the same cells. `lib/routing.py` loads `lib/tables.py` beside `lib/blocks.py`, and a copy of it taken without `lib/tables.py` stops with a sentence that names the file.
- **A table row written without its closing pipe is read wherever GitHub renders it as a row.** `lib/tables.py#gfm_table` refused such a row, so `seal pact` and `seal settle`'s reading of a plan's `## Judgments of the run` stopped at it. It now reads the row as cmark-gfm does, including a row whose last cell ends in an escaped pipe or a lone backslash, and `settle --draft` accepts such a row as a `to` it places.
- **A text holding a character Python ends a line at and GitHub does not is read by GitHub's lines.** `str.splitlines` also ends a line at U+2028, U+2029, NEL, a form feed, VT and `\x1c` to `\x1e`. A routing cell holding a U+2028 was cut there, and `gfm_table` refused a table that held one. Every reader now hands the walk the lines `lib/blocks.py#gfm_lines` gives, so the routing cell reads whole, and `gfm_table` reads each such table as cmark-gfm renders it or refuses it with a sentence naming the line. `seal pact` counts a near or second header at the line GitHub ends, one less for each such character above it. No rule document and no other work item's record holds any of the eight characters.
- **The paste check and `chain-check`'s copy notice read fences as every other reader does.** `skills/settle/scripts/passages.py` opened a fence on three backticks at any indentation. So a backtick run four spaces in at the top level of a rule document hid the words after it from the check, up to the next line that holds nothing but a run of at least as many backticks. It now takes its lines and fences from `lib/lines.py#readable`, where a fence opens three spaces in at most. One rule document reads differently: `docs/releasing/release-checklist.md`, whose backtick lines six spaces in under a list item are an indented code block, not a fence. Their words are now compared, and no other rule document shares a run of them.

### Changed

- **A row indented four spaces or a tab is no table row in any reader**, as cmark-gfm renders it as code. The routing reader, `lib/gaps.py` and `seal fold`'s index reader read such a row before. No committed record holds one, and every committed `routing.md` reads the same before and after.
- **A row holding a pipe after an even run of backslashes is refused by `lib/gaps.py` and skipped by the routing reader and `seal fold`'s index reader**, which read it before. `lib/tables.py#table_cells` refuses the shape, because cmark-gfm splits it otherwise. No committed record holds one.

### Removed

- **The second row splitter and the second line split.** `lib/lines.py#split_row`, `skills/code-review/scripts/chain_check.py#table_rows`, `lib/blocks.py#walk_text`, `lib/tables.py#gfm_line_starts` and `GFM_LINE_ENDS`, the `text` parameter of `lib/tables.py#fence_map`, `#hidden_lines` and `#unfenced` and of `lib/routing.py#shown`, and the six `# exempt from splitlines` markers in `lib/` and `skills/verify/scripts/pact_check.py`.
- **`gfm_table`'s two refusals that named a character only Python ends a line at**: a header that "shares a line with the line beside it to GFM", and a row "which is not a row of its own to GFM".
- **`passages.py`'s own fence rule and line split**, `FENCE` and `_lines`.
