### Fixed

- **The core's closing line names its two files relative to the plugin's root, so an installed plugin's printed core holds that root once (#1641).** The `SessionStart` hook printed the plugin's root three times in a user's repository: in the first line and in both absolute paths of the closing line. Measured on 2026-11-27 with release 0.39.2's core, the output under the default root of a 14-character home directory, a 63-character root, was 9,979 characters, and 9,980 with the newline the hook writes after it: 20 under the harness's 10,000-character cap. It passed the cap at a home directory longer than 20 characters. The closing line now names `skills/implement/orchestration.md` and `skills/code-review/SKILL.md` and says both are relative to the plugin's root. A clone's core, which a session in a clone of this repository receives, is closed by a sentence naming the running plugin's root instead. With the same core, the output at a 63-character root is 9,897 characters, and a root up to 165 characters prints whole. The issue first gave the installed figures as the root once and 9,939 characters, from a script that passed the checkout as the plugin root. The figures here are the work item's re-measurement.
- **An output that would reach the cap is no longer cut by the harness (#1641).** Past the cap, the harness keeps a preview and the closing line is lost. Where the whole output would reach it, the hook now prints one line naming the core's file for the session to open, above the closing line. The line opens with `AgenticSeal core:`, so a session reads it as no core printed. `seal payload` counts that line for its hook row in such a tree, marks the row `named` in its JSON, and its note says the session opens the core itself and the row does not count it.
- **The test of the cap no longer depends on where the checkout stands (#1641).** `tests/lib/test_core.py#test_the_trees_core_stays_under_the_harness_cap` measured the output at the checkout's path, which stood in it three times, and failed in clones deeper than about 70 characters. It now measures the output at a plugin root of `lib/core.py#ROOT_ROOM` characters, 100, and its failure message prints the length, the cap and that room. `CONTRIBUTING.md` says a sentence added to the core fits in what the case leaves, or the change removes as many characters as it adds.
- The version moves to 0.39.3.
