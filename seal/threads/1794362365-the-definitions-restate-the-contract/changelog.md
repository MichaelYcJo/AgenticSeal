### Changed

- **No agent removes its scratch directory, and contract rule 17 states the scratch rule once (#1503, #1474).** Rule 21 asked each agent to remove its directory with one `rm -rf` before it handed back. A crafter then closed a phase with a loop of `rm` on a variable path instead, and Claude Code held the command until the owner answered. Rule 17 now says that an agent's files outside the working tree sit under `<scratchpad>/<work-item-id>/<leaf>/`, that the name keeps a parallel agent's files apart because the agents of one session share one scratchpad, and that no agent removes the scratchpad, a scratch directory or a file in one. An agent that finds its directory already standing leaves it and adds `-2` to the leaf, or takes the next number free. The rule keeps the stopping of processes by PID, the ban on a glob delete in a shared directory and the report of a leftover. Rule 21 loses its removal sentence, and rule 7 keeps what stands under the scratch directory while everything else a probe made still goes. The one removal left is the orchestrator's: once the pull request is open, it removes the work item's scratch directory, `<scratchpad>/<work-item-id>/`, in one `rm -rf` whose path is written out in full, and nothing else of the scratchpad, because nothing clears a session's scratch when the session ends. A work item's clones of review rounds and audits now stay until then, and a work item that opens no pull request keeps them.
- **Each agent definition names its scratch directory and cites rule 17 for the rest (#1474).** The crafter keeps `phase-<n>/` and `fix-<n>/`, the proofer `round-<n>/` with its clone, the framer `frame/`, and the sealer `at-base/`. The tracer names none, so its leaf is its own name, and its probe "leaves nothing outside your scratch directory (rule 7)" where it left "nothing behind".
- **The definitions cite contract rules 2 to 5 where they restated them, and the crafter and the sealer lose their inner repeats (#1474).** The crafter's hand-back, the sealer's last step and both agents' *Never* lists cite rules 2, 3, 4 and 5 for the labels, the declined instruction and the claims. The proofer's rule *The implementer's account is a claim* takes the list its *Never* bullet held. The SDD file set*, or in contract rule 6 and `docs/running/the-run.md` *The run*. The sealer's description no longer lists its own steps, and its step 2 says once what stands above the body's line.
