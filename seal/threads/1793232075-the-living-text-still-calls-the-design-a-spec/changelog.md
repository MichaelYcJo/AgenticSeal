### Changed

- **A work item's design is no longer called a spec, and its closing memo no longer an overview (#1110).** 0.23.0 moved the design to `frame/design.md` and kept the old word. The design template now opens `# Design:`. The closing memo template opens `# Closing memo:` and ends with `## Fed back into the design`. The agents, the `implement`, `settle`, `legacy-parity` and `commit-pr-convention` skills, and both READMEs say "design" and "closing memo". `seal settle`'s dry-run headings, its `--help` line and `seal --help`'s `settle` line say "released designs". `seal unverified`'s summary counts closing memos. The commit-pr-convention mirror path names `threads/`. Two cases that globbed `seal/specs/` after the 0.23.0 move read `seal/threads/` again: every committed `guarantee.md` is checked for one verdict line, and every committed pull request mirror for a language name. `spec` stays where it names a policy document, a reference root, the release-note marker, the methodology or history.
