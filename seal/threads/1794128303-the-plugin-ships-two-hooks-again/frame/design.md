# Design: 1794128303-the-plugin-ships-two-hooks-again

Issue #1430. Version 0.33.0 (#1376) removed every command hook because the
plugin directory refuses one. The directory still holds `dist` on other
findings (#1420), so no listing is possible for now, and on 2026-11-08 the
owner decided to ship the two hooks worth having again: the stamp's `Stop`
hook, in place of the launcher a person installs, and a `SessionStart` hook
that prints the core where a `seal/` root stands, in place of the entry
skill. The owner's words are quoted where a decision is theirs.
