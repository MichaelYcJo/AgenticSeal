### Changed

- **The behaviour suite is a smoke run for gross breakage of an agent's output, and its pass no longer claims that a rewrite is not worse (#1254).** `evals/scripts/noninferiority.py compare` judged a rewritten preload by five pass rules: recall, the false-finding rate, the shape and reach graders, the preload's bytes and the tokens read. The measurement of 28 compare records found one fail later confirmed as a defect, and the shape graders read it. The verdict now keeps that rule's three clauses as rules 1 to 3: the shape and reach graders both sides ran pass no fewer runs, pooled; none fails every new run where the baseline passed it; and one the baseline lacks passes every new run. Recall, the false-finding rate, the tokens, the tool calls and the preload's bytes are still written in the record and judge nothing. A side whose token count, tool calls or preload bytes are unknown now gets a verdict instead of `no result`. A record `compare` writes opens with `# <agent> — phase <N> smoke run` instead of `non-inferiority`, and a reason line ends in `(rule 1)`, `(rule 2)` or `(rule 3)`. `evals/README.md` *The behaviour suite* says so, and says that the proofer's reading of the diff judges whether a rewrite means the same; the README bullet in both editions says the cases are a smoke run for gross breakage.
