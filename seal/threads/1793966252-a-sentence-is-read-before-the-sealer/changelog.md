### Changed

- **The pull request body opens with the work item's `pr.md`, a committed record that every review round reads (#1415).** The orchestrator wrote the body's first part after the last round, so the sealer was the first party to read it. The orchestrator now writes `seal/threads/<work-item-id>/pr.md` once the build's last phase has closed, and commits it before it spawns the first round, or before the broad run where no round runs. It holds the `Closes` and `Part of` lines, quotes of the work item's records, each followed by its coordinate, and the attribution line. It holds no sentence of the orchestrator's own account. A quote is in `Record language`, as its record is, and the other lines are in the language `Commit and pull request language` names. Where a fix pass or a fold changes a sentence `pr.md` quotes, the orchestrator rewrites the quote and commits it before the next round. Before each spawn of the sealer, it finds each quote verbatim at its source. A round finding located in `pr.md` is the orchestrator's to repair, and the fix pass's close block reads `fixed <that commit>`.
- **What the orchestrator wrote in its own words leaves the body (#1415).** The broad run's printed figures and a CI run taken after the rounds no longer stand in the body; the records' copy carries `trail/gate.md`'s `run:` line. The run's comparison table goes to the flow log's comment alone. The lines only `seal gate` prints, such as where resolving the base moved it and its `outputs kept under` line, go to the orchestrator's report to the person. Why the title takes its prefix is a row of `frame/plan.md` *Judgments of the run*, which `pr.md` quotes, and the framer's judgment left after the exchange is quoted from its *Alternatives considered* row.
- **`seal pr-body` writes `pr.md` as the body's first part, and `--check` compares that part with `pr.md` (#1415).** The writing form writes `pr.md`'s bytes, then the line `## From the records`, then the records' copy, and replaces whatever the body file held. `--check` refuses each line above `## From the records` that differs from `pr.md`: a line changed, a line the body adds and a line the body lacks, each at its line of the body. Both forms refuse a work item with no `pr.md`, and a line of `pr.md` that reads `## From the records`. The command now prints ``wrote: <file> from <item>'s `pr.md` and records`` and ``matches: <file> is `pr.md` above `## From the records` and the records' text below it``. The exit codes are unchanged.
- **Every review round reads the work item's records that state the present, whole, against its target (#1415).** A finding round and a verifying round alike read `routing.md`, `frame/design.md`, `frame/plan.md`, `frame/questions.md`, `gaps.md`, `changelog.md` and `pr.md` to their end. Each sentence the target contradicts is a finding located in its file, and so is a quote of `pr.md` not found word for word at its source. A verifying round stays inside the fix diff for the code it reviews and reads the records beside it.
- **The party that builds a work item writes its changelog fragment and moves the version in the commit that adds it (#1415).** Under `Implementation` `crafter` that party is the last phase's crafter, and `agents/crafter.md` names the version move as its write where `frame/plan.md` *Operational impact* names one. The orchestrator still chooses which work item carries the move. Where a crafter builds that work item and its *Operational impact* does not name the move, the orchestrator folds the move into that section before it spawns the last phase. The *Operational impact* placeholder of `templates/records/sdd-plan.md` names the move and the phase whose commit carries it.
- **A framer states a count of a list once, beside the list (#1401).** Every other sentence of the three frame files that needs the number cites the list by its coordinate, so a fix or a fold that changes the list changes one number.

Updating: a work item that is in flight at the update and has no `pr.md` is refused by `seal pr-body`, whose `refused:` line names the work item's `pr.md` and says it `is not there; the orchestrator writes it before the first round`. Write `pr.md` in the work item's directory, commit it, and run the command again.
