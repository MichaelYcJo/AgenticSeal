## Operational impact

No migration, no environment variable, and no dependency in the tree. The icon and the `.png` preview are drawn outside the tree with `resvg_py` 0.5.0 and Pillow 13.0.0, and the README names both with their versions. The stamp a user sees changes look at 0.25.1 and gets smaller: 5,725 UTF-16 units for the widest reference panel against 5,959 today, under the 9,000 budget. A values file queued by 0.25.0 is drawn by 0.25.1's hook with the new disc, because the file carries rows and no disc. `TRADEMARKS.md` is copied into the installed plugin with the rest of the repository's root, as `LICENSE` is, but the loader reads neither and the user runs neither, so it is classified in `STAYS_HOME` and a change to it alone moves no version.
