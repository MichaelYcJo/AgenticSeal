### Fixed

- **`seal mutate` now refuses a `.py` mutant that does not compile, before it writes anything or runs a case (#898).** The command breaks one unit of a file and runs the cases that cover it, and it read any failing run as `red`, exit 0: the cases caught the break. A mutant with a syntax error fails every case that loads its module, whatever the unit does, so a typo in the break passed for a caught defect. For a target whose name ends in `.py`, the command now compiles each mutant with Python's builtin `compile`, over the bytes it would write to disk, and a `SyntaxError` is the existing `refused` verdict at exit 2. The refusal names the file, the error's line where the error has one, and its message, and says that nothing was written and the cases did not run. In a call holding several mutants, one that does not compile refuses the whole call and is named by its place, `pair <n>:`, as a pair that does not land exactly once already is, and no case runs. The file as it is gets compiled first. Where it does not compile under the interpreter running `seal`, no mutant is compiled and the verdict comes from the cases' exit code as before. The first line printed then says the mutants were not compiled, with that interpreter's version and the error's line, because the cases may run under another interpreter that reads the file. No other kind of file is compiled or parsed, so a `.md`, `.yml`, JSON or TOML target, or a script with no `.py` suffix, runs as before. Two limits are stated in `skills/verify/SKILL.md`: the compile uses the grammar of the interpreter running `seal`, not the cases', and a mutant that compiles and then fails at import is not refused.
- **A red line in a call holding several mutants now carries the cases' exit code (#898).** The line read `mutant <n>: red (<s>s)` and now reads `mutant <n>: red (exit <N>, <s>s)`, as one mutant's line already carried the code. The command decides nothing from it. Under pytest an exit of 2 is a collection error, and an exit of 1 is a failing case or an import error raised inside one, so the reader can tell a red that came from collection apart, and run one pair alone to see its output. Every other line, and every exit code, is unchanged.
