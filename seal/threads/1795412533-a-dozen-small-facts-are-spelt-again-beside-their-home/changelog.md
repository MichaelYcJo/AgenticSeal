### Changed

- **The suite's packages have one home, `tests/requirements.txt` (#1575).** `bin/test` builds its `.venv` with every line of the file, and adds each pinned line to an adopted `.venv` that lacks that version. `.github/workflows/test.yml` and `.github/workflows/publish-release.yml` install the file with `pip install -r`. `pytest-split` stays CI's alone, pinned on the install line of `test.yml`. The two fallback commands of `CONTRIBUTING.md` *Running the checks* read the file: `uvx --with-requirements tests/requirements.txt python3 -m pytest tests/ -q`, or `pip install -r tests/requirements.txt && python3 -m pytest tests/`. They now install `pytest-xdist` too, and still run the suite serially, since neither passes `-n`.
- **`bin/test` names the requirement alone where it adds a pin or fails to.** Its line reads `bin/test: adding <requirement> to <.venv>.`, without what the package is for. Where the install fails, its sentence says that a test module importing the package fails to collect, where it named the one module that imported it. A `tests/requirements.txt` that cannot be read stops `bin/test` at exit 2 with `bin/test: cannot read <path> (<reason>)`, before anything is built.
- **`seal gate` loads `chain_check.py` before its first arm.** Where the module is absent, the gate stops at exit 2 with the loader's sentence and runs no arm. Before, it ran every arm and failed at the chain arm. A `chain_check.py` that raises while it loads ends the gate at exit 1 with its traceback, before any arm runs. The chain arm passes the `--sealing` flag `chain_check.py` defines.
- **The non-inferiority eval reads an agent's `skills:` list in every form `payload_meter.py` reads.** The flow form `skills: [a, b]` and CRLF line ends are among them, where the eval read the block form, split at LF, alone. A definition whose frontmatter declares no `name:`, or that has no frontmatter, stops the run with ``<file> declares no `name:` in its frontmatter``. Before, only a definition with no frontmatter stopped it, with `<file> has no frontmatter`.
