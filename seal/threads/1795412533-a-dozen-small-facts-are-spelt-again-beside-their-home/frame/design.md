## Data & interfaces

The new units, by module. Each name is the frame's; the build keeps it unless a phase record says why not.

- `lib/optin.py#opted_out(common)`: True where `common` is not empty and the file `SCRATCH` stands under it; a directory of that name is no opt-out.
- `lib/optin.py#marked_home(root, common=None)`: the first of `home_paths(root, common)` that is a directory carrying the marker, or ""; the opt-out is not read.
- `lib/config.py#declared_policy_root(home)`: `(rel, refusal)`. `refusal` is the refusal `declared_value` gives for `POLICY_KEY`, or None. `rel` is the normalised value, or `POLICY_DEFAULT` for every case the docstring of `#policy_root` lists.
- `lib/config.py#policy_group(path, policy)`: for a `/`-joined PATH that is `<policy>/<name>.md` or `<policy>/<group>/<name>.md`, with no `/`, `\` or `:` in a part and a group that is neither `.` nor `..`, it answers "" at the top level and the group's name in a group. It answers None for every other path.
- `lib/config.py#switch(home, key, off)`: `(on, note)`. On where KEY reads `SWITCH_ON`, the value `yes`, exactly. Off and silent where there is no root, no key or an empty one. Off and named for any other value (`SWITCH_NOT_YES`) and for a refusal (`SWITCH_NOT_READ`), with OFF closing the sentence. The two sentences are those of `pr_body.py:332-336`, with the key and the closing words as fields.
- `lib/blocks.py#FENCE_RUN`: the pattern of a run of three or more backticks or three or more tildes.
- `lib/gitcmd.py#inside(path, top)`: True where PATH is TOP or under it, each taken absolute, by `os.path.commonpath`, so a relative path keeps the answer its caller gave it; False for two drives. The paragraph of the module docstring on its path helpers names it.
- `lib/console.py#plural(count, word, many=None)`: `1 <word>`, or `<count> <many>` where MANY is given, else `<count> <word>s`.
- `lib/routing.py#read_declaration(path)`: `parse` of the file at PATH, or None where it cannot be read or decoded.
- `tests/requirements.txt`: one requirement per line in pip's syntax, with `#` comment lines; a pinned line is `<name>==<version>`.
