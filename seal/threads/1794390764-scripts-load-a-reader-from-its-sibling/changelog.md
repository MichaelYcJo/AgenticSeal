### Changed

- **A script of the plugin copied out and run on its own says one sentence about what it lacks (#1482).** Each script now reaches every other module of the plugin through `lib/sibling.py`. Where a file it loads is absent, it prints `cannot read <path>, which this command loads. It ships in the plugin beside this script; a copy of one script taken on its own is not a plugin. Nothing was read.` and exits 2. `<path>` is the absent file's absolute path. Before, the scripts that reported an absent file each did so in a sentence of their own, naming what the file was for. `chain_check.py`, `pr_body.py` and `broad_gate.py` print the new sentence where they printed a line of their own. `rules.py` and `release_report.py` print it when their arguments reach a load. In a whole plugin, no command's output or exit code changes.
- **A lone copy of `settle.py`, `fold_check.py`, `pact_check.py` or `payload_meter.py` run with `--help` exits 2 in that sentence (#1482).** It printed its help at exit 0. A copy without `lib/` can run nothing its help lists, and a bare run of the same copy already exited 2.
