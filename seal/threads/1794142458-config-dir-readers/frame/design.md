## Scope

In:

1. **`session_cost.py` reads transcripts in the config directory in use.** The constants `HOME` and `PROJECTS` (`:82-83`) give way to a function, `projects_dir()`, that reads the variable at each call and returns `<config>/projects`, where `<config>` is `os.environ.get("CLAUDE_CONFIG_DIR") or os.path.join(os.path.expanduser("~"), ".claude")` (G3). `newest` calls it in place of `PROJECTS`. The docstring sentence at `:41` and the comments at `:2880` and `:3100` name the directory as `${CLAUDE_CONFIG_DIR:-$HOME/.claude}/projects` in place of `~/.claude/projects`.
2. **`payload_meter.py` reads the user-level `CLAUDE.md` and skill shadows in the config directory in use.** The meter takes the config directory as an input beside `home`, and `home` keeps its one other use, a `@~/` import (G6). The shadow read at `:461` and the pair's second file at `:480` stand under that directory. The labels and the interface are *Data & interfaces*. The module docstring's two statements of the fixed location (`:8`, `:69`) name the user's config directory.
3. **The prose names the config directory in use.** `skills/verify/orchestration.md:241`, `README.md:317` and `README.ko.md:316` spell the directory `${CLAUDE_CONFIG_DIR:-$HOME/.claude}` in place of `~/.claude`, inside the code span each already has.
4. **The suite runs with the variable unset.** `tests/conftest.py` removes `CLAUDE_CONFIG_DIR` from `os.environ` at import, beside the `GH_CONFIG_DIR` block, with a comment saying why (G9). A case that needs the variable sets it.
5. **A case per reader runs under a scratch `CLAUDE_CONFIG_DIR`** (test-first; contract rules 14 and 15). The cases are the acceptance rows S1 to S6 below. `Test_newest` sets `HOME`, `USERPROFILE` and `CLAUDE_CONFIG_DIR` with `monkeypatch.setenv` in place of patching `PROJECTS`, since `os.path.expanduser` reads `USERPROFILE` on Windows, and `project_of` reads `module.projects_dir()`.

Out:

- **The plugin's own state under `~/.claude/agentic/`**: `pact_check.py`, `docs/layout/the-pact.md:147`, `skills/legacy-parity/SKILL.md:32`, `skills/parity-setup/SKILL.md:54` and `templates/setup/parity.md:10`. The plugin chose to keep these files there, and Claude Code does not keep them, so a set variable does not make them stale (the issue's own text).
- **`docs/experiments/2026-09-03-skill-preload-and-the-copy-in-force.md` and its Korean copy**: a dated record of what was measured on one machine where the variable was unset. #1184 left it out on the same grounds.
- **`CHANGELOG.md` and the records under `seal/threads/`**: history.
- **An empty or relative `CLAUDE_CONFIG_DIR`** (G5): a limit, and nothing is built for it.
- **A text check that refuses a fixed `~/.claude` across the shipped tree**: `plan.md` *Alternatives considered* row 5 holds the grounds.
- **`seal cost --latest`'s "no transcript found" line** (`session_cost.py:3203`): it names the directory the transcript was looked for under, not the projects root, and this work leaves its text as it is.

## Data & interfaces

- **`session_cost.py`**: `HOME` and `PROJECTS` leave. `projects_dir()` takes no argument and returns `os.path.join(os.environ.get("CLAUDE_CONFIG_DIR") or os.path.join(os.path.expanduser("~"), ".claude"), "projects")`, read at each call. `newest(directory)` keeps its signature and its slug rule.
- **`payload_meter.py`**: `measure` gains the keyword `config=None`, the value of `CLAUDE_CONFIG_DIR` as the caller read it. `main` passes `os.environ.get("CLAUDE_CONFIG_DIR")`, and is the one place the meter reads the variable, so a call that passes no `config` reads only the `home` it was given. One function, `user_dir(home, config)`, returns the directory and its label: `(os.path.join(home, ".claude"), "~/.claude")` where `config` is `None` or empty, and `(config, "$CLAUDE_CONFIG_DIR")` otherwise. `measure` threads that pair into `session_composition`, `composition` and `pair_rows`, whose `home` argument stays for `imports_of`. The labels are `<label>/CLAUDE.md` and `<label>/skills/<name>/SKILL.md`; an import row's label is built from them as it is today. Under an unset variable every label, JSON key and table line reads as at `b2a04d6d9`.
- **`tests/conftest.py`**: `os.environ.pop("CLAUDE_CONFIG_DIR", None)` at import.
