## Scope

In:

1. **A census `slash_in_join` in `tests/censuses.py`, added to `CENSUSES`.** It reads every tracked `.py`, as `encoding` does. It flags each call whose function resolves to `os.path.join` through the file's imports, by `bindings` and `dotted`, where a positional argument is one of three things: a string constant holding `/`; an f-string whose literal parts hold `/`; or a bare name the file binds exactly once at module level, by an assignment of a string constant holding `/`. The flagged line is the line the call starts on. The message names the value and the repair: pass each part as its own argument, `*NAME.split("/")` for a constant, or put `# exempt from slash_in_join: <why>` on its own line above the call. The census's section opens with a comment block, as `encoding`'s does, that says why the reading is an AST walk, cites run 40500883542 as the record, and lists what the walk cannot see: a constant imported from another module, a name bound more than once, a `/` added by concatenation, and a `/` built into a string outside `os.path.join`.
2. **Cases for the census in `tests/test_censuses.py`**: a class `Test_slash_in_join`, and a class for each public helper the census adds, each with its `test_accepts_` and `test_refuses_` cases, shown red as contract rule 15 asks.
3. **The tree brought to the census.** Every site the census flags at the build's HEAD is rewritten, joining each part as its own argument, or carries the exemption where the `/` is the value the case is about. At `e2f197dc` those are the 11 sites in *Grounding*. The two sites that join another module's constant, `skills/verify/scripts/seal_stamp.py:1417` and `.github/scripts/finding_counts.py:200`, are rewritten the same way, though the census cannot see them.
4. **`CONTRIBUTING.md` *House rules* gains one bullet, beside the encoding one.** It states that a path is joined one part at a time, why the Windows leg is the only place a `/` inside a join shows, and that the `slash_in_join` census in `tests/censuses.py` holds it over every tracked `.py`.

Out:

- **#32's link-case remainder, the three cases of `tests/skills/test_agentic_pytest_record.py#Test_module` gated on the platform.** They are #1247's work item `1793922919-three-link-cases-skip-on-windows-by-platform`, on branch `test/1247-three-link-cases-skip-on-windows-by-platform`, at commit `b97741a0` (*Grounding*). Building them here too would edit the same lines on two branches.

- **#103's second ask, a code-review checklist question for a defence resting on a POSIX-only guarantee.** Contract rule 13 states it and binds the proofer (*Grounding*). A checklist row would state it twice.
- **Dropping the Windows claim.** The issue recommends against it, and its ground holds (*Grounding*; `plan.md` *Alternatives considered*, row 6).
- **#32's per-hook cases that render a hook's message under `ntpath`, and the helper for them.** The hooks it names are gone or print no path, and the one hook with a recorded failure already has its case (*Grounding*). A case for a hook with no recorded catch is a mechanism with no record.
- **#32's exemption for `chain_check.py`.** Moot: the census reads `os.path.join` only, and `chain_check.py` builds its git paths otherwise.
- **Reading constants across modules in the census.** A census judges one file at a time (`tests/censuses.py:1-13`), and a module's `census_case` would depend on other files. Scope item 3 rewrites the two sites by hand, and the census comment names the limit.
- **A `/` built into a string a person types, and the platform separator written where `/` was meant.** These are the shapes of the issue's first defect and of the 969 failure. Neither is a fact a parser gives: a `/` in an f-string is right for a git path or a URL, which is why #32 kept `chain_check.py` out.
- **Running the other platforms before the broad run for every work item.** That departs from #943's owner decision; `questions.md` Q2 holds it.
- **The version move to 0.32.6.** Another work item of the release carries it.
