### Added
- **A `/` inside an `os.path.join` argument is refused where the change is made, and is no longer met first on the Windows leg (#103).** `os.path.join` keeps a `/` inside an argument and writes `\` between the arguments on Windows. The path then mixes the two separators, and only a case that compares it as a string notices, on the one leg nobody runs locally. Run 40500883542 met this at a pull request, through the constant `GATE_FILE = "trail/gate.md"`. A new census in `tests/censuses.py`, `slash_in_join`, reads every tracked `.py` with `ast`. It refuses an `os.path.join` call under any import spelling where an argument is a string holding `/`, an f-string whose literal part holds `/`, or a name the file binds once, by a module-level assignment of such a string. Its line names the value and the repair: pass each part as its own argument, or `*NAME.split("/")` for a constant. Each module file's census case runs it, and so does `tests/test_censuses.py` over every other tracked file. A constant imported from another module is outside its reach. `CONTRIBUTING.md` *House rules* states the rule.
### Changed
- **Four scripts the plugin ships now join a path one part at a time, so on Windows each spells it with `\` throughout (#103).** They are `skills/settle/scripts/rule_changes.py`'s reader of the pending designs, `evals/scripts/noninferiority.py`'s removal of the suite before it extracts one, `skills/verify/scripts/seal_stamp.py`'s read of a work item's `trail/gate.md`, and `.github/scripts/finding_counts.py`'s directory of each released work item. On macOS and Linux each path is the same as before. Windows opened the mixed spelling too, so no user-visible failure is repaired. Nine test sites the census flagged are joined the same way.
