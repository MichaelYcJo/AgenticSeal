### Changed

- **Test docstrings and comments no longer describe the commit gate or its git hooks as standing (#1352).** #1027 removed the commit gate and the git hooks it ran through, and twenty-one places under `tests/` still said the gate reads a declaration, asks again at the next commit, or un-silences, said its per-command waiver stands, or listed a git hook among what runs before any Python floor. Each now names the mechanism that does the job today, drops the clause, or goes. Where the sentence is about a declaration that cannot be read, it now says the edit check, `hooks/routing-edit-gate.py`, refuses the next edit on the branch. Two docstrings in `tests/hooks/test_routing.py` pointed at a hook-level case for a malformed declaration that does not exist, and the pointers are removed. `tests/conftest.py#fired`, a helper nothing called whose docstring described the gate's two prompts, is removed. The first paragraph of `tests/behaviour/test_a_commit_names_its_repository.py` loses the gate half and its measurement. One assertion's failure message in `tests/hooks/test_routing.py` now says what an optional row read wrongly would give, and no assertion's predicate changes. Lines that say the gate is gone, or tell what it did in the past tense, stand. No check is added to keep the wording out, because a spelling check cannot tell a present-tense sentence from a past-tense one.
