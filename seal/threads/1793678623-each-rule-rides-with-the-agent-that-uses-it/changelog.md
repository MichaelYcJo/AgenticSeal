### Changed

- **Rules that only a builder acts on leave the contract every agent preloads (#1313).** Every agent receives `skills/core/SKILL.md` and `skills/agent-contract/SKILL.md` with its own definition on every spawn, so each sentence in them costs every spawn its bytes. Contract rule 16, that a commit writes the repository's absolute path after `git -C` in a command of its own, now stands in `skills/implement/SKILL.md` *2. Implement test-first, and let each rule name its test* as *A commit names its repository in the command that makes it*. The crafter, the session that builds and the orchestrator all read that file. Every other agent commits too, the framer where a spawn prompt asks and any agent whose probe commits in its clone, and no step of theirs opens that section, so contract rule 6 keeps one sentence: a commit an agent makes, a probe's included, writes the repository's absolute path after `git -C` in a command of its own, as that rule states. The set of tests a builder runs at a phase boundary, which contract rule 2 named, now stands in the *Phase boundary* row of `skills/verify/SKILL.md` *Scope: cheap and often, broad and once*, and `agents/crafter.md` step 7 cites that row. Rule 2 keeps the slice tests, the broad gate and the `unverified` hand-over. `skills/implement/orchestration.md` and `skills/implement/multi-repository.md` cite the commit rule at its new home. A spawn prompt that cites `contract rule 16` now names a retired number.
- **A retired contract rule leaves the file, and the contract's preamble lists its number (#1313).** Rules 8 and 20 had stayed as one-line sections naming what replaced them. The preamble now says that a rule that retires leaves the file and its number is listed there, that the retired numbers are 8, 16 and 20, and that a new rule takes the number after the highest one used, retired or not. `tests/text/test_the_agent_contract_holds_the_universal_rules.py` reads that list. The headings must increase and repeat no number, every number missing up to the highest used must be listed, and no listed number may be a heading. The case cannot see the highest number used leave both the list and the file, and its docstring says so. `tests/behaviour/test_a_probe_that_commits_says_so.py` loses the case that read rule 8's body.
- **Text that every agent received twice now stands once (#1313).** All five definitions said that their `skills/`, `templates/` and `docs/` paths are the plugin's, at the root two directories above the base directory the harness prints. Contract rule 11 now says it once, for `agents/` paths too, under the heading *Where the plugin's paths and the `seal/` root resolve, and the record language*. The crafter's and the framer's definitions no longer restate how a reference root is read, which `skills/implement/SKILL.md` *Document layout — two roots, three lifetimes* states. The proofer's and the sealer's step 5 no longer restate the parity record's `original:` line, and cite `skills/legacy-parity/SKILL.md` *Recording the comparison* for it. The sealer's step keeps the condition under which it compares. The framer's *The one route back is the review chain's* no longer says what a builder does when the frame does not hold, which `agents/crafter.md` *The frame is judged before it is built to* says. The contract's preamble no longer says how the file arrives or that a role's rules live in its definition. Every definition's opening sentence and the core's *Each agent judges its own target* say those. Rule 19 cites the core's *The rule a mechanism is kept against* for the rule it restated, and keeps its method.
- **Every agent's preload is smaller (#1313).** Measured by `.github/scripts/release_report.py` against v0.30.0, the crafter's preload falls from 33,081 to 31,730 bytes, the framer's from 36,362 to 34,836, the proofer's from 32,293 to 30,840, the sealer's from 31,879 to 30,556 and the tracer's from 25,085 to 23,970. Across the five definitions, the contract and the core, the words inside a ten-word run that another tracked file outside `seal/` and `tests/` also holds fall from 934 of 11,209 to 766 of 10,769. `skills/implement/SKILL.md` grows by 721 bytes and `skills/verify/SKILL.md` by 111, paid only by a party that opens them.
