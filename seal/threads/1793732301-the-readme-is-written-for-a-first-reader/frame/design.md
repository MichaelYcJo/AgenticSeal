## Scope

In:

1. **`README.md` is written new, for a developer meeting the plugin for the first time**, from the plugin as `release/v0.31.0` leaves it at 29182a206. Neither the old sections nor `assets/demo.gif` serves as a template. The page opens with these, in order:
   - the owl, `assets/seals/owl.svg`, centred above the title as an HTML `<p align="center"><img …></p>` with alt text;
   - `# AgenticSeal`;
   - the `.claude-plugin/plugin.json` `description` sentence, verbatim, as the paragraph directly under the title, wrapped to the 88-column limit;
   - one line with the tests badge and the language switch;
   - a short account, one paragraph, of what the plugin does for this developer: you hand Claude Code an issue; you answer one routing question at the start; agents frame, build, review and seal the change; the run ends at a pull request carrying a seal bound to a commit, and never at a merge. Why that differs from asking one agent to review its own work, and the claim labels, follow `## Install`, below the first screen, in the words the page gave them before the move, the first sentence's subject named ("This workflow differs") since "That" would point back at the install;
   - the workflow as a `mermaid` flowchart, left to right: issue, the routing question, framer, crafter, proofer with fix passes, the broad gate, sealer, pull request;
   - `## Install`, with the three commands `claude`, `/plugin marketplace add MichaelYcJo/AgenticSeal` and `/plugin install agentic@agenticseal` in the block directly under the heading, and the Python 3.12 requirement after the block.

   The owl's width, the paragraph's length and the chart's direction are set so that this first screen fits one viewport: rendered as S1 measures it, the install block's last line stands within the first 900 pixels.

   After the first screen, the page walks the reader through a first work item, then explains how the plugin works, what runs on the reader's machine, the commands, the limits, contributing, the language policy and the license. `frame/plan.md` *Technical context* gives the outline.
2. **Every fact the page holds that another shipped file already states is linked to that file, not restated.** Each of these goes this way: the agents' long table cells, K3.1, K3.2, the `seal/` tree, the review chain's bound, the broad gate's words, the mode switch's rules and its by-hand lines, the export and import refusal list, `seal unverified --baseline`'s footing, and each command row's detail. `## Removes` names each one with its home. A fact with no other shipped home stays on the page, tightened: the hook inventory with one row per registered script, the side effects, the hooks that reach the network, and the limits.
3. **`README.ko.md` is written new in Korean from the new English edition's story, with the same sequence of heading levels.** The Korean version-check row carries the clause the English row carries (K4).
4. **`BASELINE` and the ratchet leave `tests/text/test_no_passage_is_pasted_into_a_second_file.py`.** `over_baseline` becomes a reading that names every pair sharing any run. The module docstring's *Why a ratchet* paragraph and the comment over `BASELINE` go. The two cases that hold the ratchet's edges, `test_a_count_over_its_baseline_is_named_and_one_at_it_is_not` and `test_a_removed_copy_passes_without_a_baseline_edit`, go with it, because the behaviour they hold leaves. `test_a_paste_is_named_with_the_pair_the_run_and_the_act` keeps its assertions against the reading without a baseline.
5. **The one policy sentence that states the ratchet changes through `## Rule changes`**: `docs/layout/the-record-layout.md` *The root records*.
6. **Every case that pins a README sentence the rewrite moves or removes is repointed in the same phase**, as `frame/plan.md` *Technical context*, table *The cases that read the two editions*, bounds it. A pin of a fact the page still states moves with the fact's new wording. A pin of a fact the page now links follows the fact to its home, or leaves the case's README arm where the home's own arm already holds it.
7. **`tests/behaviour/test_chain_hooks_hardening.py::test_the_marketplace_describes_the_plugin_in_the_manifests_words` also asserts that the paragraph directly under `# AgenticSeal` in `README.md`, its line breaks folded and only a blank line between them, is the manifest's `description`.** The sentence is a copy the issue requires and no link can replace. The case already holds the other two copies, those in `.claude-plugin/marketplace.json`, for the same reason.
8. **The social preview ships as `assets/seals/owl-social.png`**, 1280 × 640, opaque, under 1 MB. It is drawn from `assets/seals/owl-social.svg`, which places `owl.svg` by `<image href="owl.svg">` on a solid field and copies none of its paths. The entry *The little owl — from 0.25.1* in `assets/seals/README.md` gains the preview's paragraph: what it is, the command that draws it with `resvg_py` 0.5.0, the fact that the owner uploads it in the repository's settings, and that nothing checks it is still the SVG, as the icon's paragraph says of the icon.

Out:

- **Uploading the social preview.** It is a repository setting only the owner can change (issue body). The pull request body names the file and the setting.
- **Removing `templates/setup/claude-md-block.md`.** The template exists so that an update from 0.24.x leaves an empty marker pair (`tests/behaviour/test_the_old_block_leaves_through_update.py` docstring). Whether any 0.24.x install still needs it is a question for the update procedure, not for the README. The page keeps the one sentence that names it.
- **A per-hook policy document under `docs/`.** No `docs/` document holds the hook inventory (read: `docs/checks/the-session-hooks.md` tables only the implementer mark and notice). A new document would be a policy-root work item. So the inventory stays on the page, below the first screen.
- **A demo recording or GIF.** `frame/plan.md` *Alternatives considered* gives the grounds.
- **The policy documents' own text**, apart from the one `## Rule changes` operation for the settle.
- **`CONTRIBUTING.md`.** Its two sentences about the README stay true: the page keeps the context-file study's link and a section that names the hooks that reach the network.
