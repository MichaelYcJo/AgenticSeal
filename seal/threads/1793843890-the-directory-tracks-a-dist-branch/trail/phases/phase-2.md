**The git commands the archive reading runs**, in `archived`:

1. `git -C <root> rev-parse --git-path index`, which names the index file.
2. The index file is copied into a temporary directory, and `git -C <root> write-tree` runs with `GIT_INDEX_FILE` set to the copy. Its output is the index's tree.
3. `git -C <root> archive --worktree-attributes --format=tar <tree>`. Python's `tarfile` reads the archive from memory, and `getnames()` gives its paths. A directory's path is among them. No citation names a directory as a file, and `on_disk` keeps only files, so a directory's path decides nothing.

**What an uncommitted change does to them.** A file staged and not committed is in the index, so it is in the tree and in the archive, and A4 pins that. A file neither staged nor committed is not in the archive, as it is not in `git ls-files`. An edit not staged to a tracked file leaves the paths alone, and its text is read from disk. A `.gitattributes` line written and not committed is read through `--worktree-attributes`, which reads the working tree's file before the index's, and A5 pins that. A tracked file the working tree deleted stays a path of the archive and is not read, as in the tree reading. `write-tree` writes the tree objects of the index into the object store and touches nothing else. An index with unmerged entries stops `write-tree`, and the archive reading with it. The module docstring states both of the last two as limits.

**A departure from the frame: the tree is written from a copy of the index.** The frame leaves the commands to the crafter. `git write-tree` on the real index takes the index's lock, and a probe in a scratch repository showed it exit 128 with `Unable to create '.../index.lock': File exists` while a lock stood (executed). Under the suite's default pytest-xdist run, the two new tree cases can run at once in two workers and take that lock together. Under a copy of the index, `write-tree` ran and exited 0 with the lock standing (executed). A6 pins this. Judged against `frame/design.md` *Data & interfaces*, the census item, which says the exact commands are the crafter's.
