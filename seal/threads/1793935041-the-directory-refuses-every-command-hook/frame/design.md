# Design: 1793935041-the-directory-refuses-every-command-hook

Issue #1376, which absorbs #1381. The plugin directory refuses `dist` because
every hook the plugin registers is a command hook. This work item removes
every hook the plugin registers, gives each hook's job a home that is not a
hook or removes the job, keeps every exact check exact, and edits in place
every document that stood on a hook. The owner's ten decisions in the issue
body are the scope; this frame settles what the body left to the frame.
