## Scope

In:

1. **On `cmd.exe`, `not_as_written` refuses a command name that starts in a directory.** The shell is `cmd.exe` where `cmd_exe_reads` says so. The gate reads the key's value up to its first `"`, `^` or `%`, because each of the three can move where `cmd.exe` ends a command. It splits that part at blanks and tabs. A word is read as a command name where it is the first word, or where the word before it is exactly `&&`, `||`, `&` or `|`. A command name is refused where it holds a `/` and the part before its first `/` names a directory under the root the command runs in. An empty part (a name that opens with `/`), `.` and `..` each name one. The refusal keeps the shape of G3: exit 2, nothing run, the `as written` line, and an `as meant` line with each refused name's `/` written `\`. Its sentence names each refused name with its `\` spelling. It says that `cmd.exe` reads a `/` in a command name as the start of a switch, and that `/bin/sh` reads the `\` spelling as another name. So a key run under both shells names its commands with no directory in front, and hands a script's path to an interpreter as an argument.
2. **What the reading leaves is named, not decided.** Where the shell is `cmd.exe` and the value holds one of the three characters, each word after the first of them that the reading would refuse without the cut is named as a word the gate did not read, with the character the reading stopped at. Where nothing is refused, that is one stderr line before the run, and the command then runs as written. Where a name is refused, the refusal carries the same line. Under `/bin/sh`, or a `COMSPEC` naming another shell, the gate reads nothing of the command for this form and names nothing.
3. **The rewriter goes, and `run` hands every command as written.** The units G4 names go, except `cmd_exe_reads` and `CMD_EXE`, which the refusal reads. So do `run`'s `windows` and `comspec` parameters, its stderr line and the kept file's second line. The module docstring's item 1 names the new refused form. `not_as_written`'s docstring counts four forms and states the reading, and its sentence *Nothing is stripped or rewritten* stays.
4. **The refusal's cases, in `tests/skills/test_broad_gate.py#Test_not_as_written`**, each driven with `windows`, `comspec` and a root built for the case, one per edge of the reading:
   - refused: `bin/test -q` on `cmd.exe` in a root that holds `bin/`, with the whole message pinned (contract rule 14);
   - the same value not refused under `/bin/sh`, under a Windows `COMSPEC` naming another shell, and in a root with no `bin/`;
   - a name after each of the four separator words is read, and a word after any other word is not;
   - a word after a separator glued to the word before it (`a&& bin/x`) is neither refused nor named, the bound *Scope* item 6 states;
   - an empty part, `.` and `..` are refused;
   - a glued switch on a program the root holds no directory for (`xcopy/e/i`) is not refused;
   - the cut at each of `"`, `^` and `%`, with the stderr line of *Scope* item 2 pinned;
   - several refused names in one value, each named and each turned in `as meant`.
5. **The real-platform cases follow the change.** `Test_run#test_refuses_the_row_only_under_cmd_exe_and_runs_it_on_the_real_platform` builds `bin/probe` and `bin/probe.cmd`. Where `cmd_exe_reads()` is true, `bin/probe` is refused naming `bin\probe`, and `bin\probe` runs under `cmd`. Elsewhere `bin/probe` is not refused and runs under `sh`. `Test_run#test_a_switch_against_a_program_runs_on_the_real_platform` keeps `where/q cmd`: not refused, and exit 0 on `cmd.exe`. The helper `runs_under_cmd_exe` gives way to `cmd_exe_reads()`. Every existing call of `not_as_written` passes a root. `test_this_repositorys_own_config_is_answered_exactly_as_before` passes `ROOT`, so no case asks about directories in pytest's working directory.
6. **`templates/setup/config.md` *Broad gate* says what the gate refuses on Windows.** The paragraph *Which shell runs the command, and what it is handed* (:256-294) is rewritten. It states the reading of *Scope* item 1 as the rule, what *Scope* item 2 names as not read, and the bounds. A word the reading takes for a command name that `cmd.exe` would not run, such as text after `rem`, is refused too. So is a glued switch where the root holds a directory of that program's name. A blank before the switch, or the `\` spelling, answers either. A separator glued to the word before it, as in `a&& bin/x` or `echo a^&& bin/x`, is no separator to the reading. So the word after it is neither refused nor named, though `cmd.exe` reads that word as a command name. A blank before the separator puts the name back in the reading. The gate reads no glued separator, because reading one is the hand model of `cmd.exe`'s lexer that the owner's decision removes. The refused table (:302-308) gains a row for the form, and the sentence at :298-301 stops counting the forms.
7. **`skills/config/SKILL.md:110-116` names the form** beside the three it names, and stops counting them.

In `tests/conftest.py#posix_row_shell_or_skip`'s docstring, the sentence that `not_as_written` reaches no shell and is right on both platforms is rewritten: it reaches no shell, and it reads the platform and the root.

## Data & interfaces

- `not_as_written(home, command, root, windows=None, comspec=None) -> str | None`. `root` is required, so no caller asks about directories in its own working directory. `windows` and `comspec` default to this machine's, as `cmd_exe_reads` reads them. `gate` passes its own `root`.
- The scan that finds the refused names takes the directory question as an argument, and every case reaches it through `not_as_written` with a root built for that case: `(command, is_directory) -> (refused, not_read)`, two lists of words in the order they stand. Its name is the crafter's.
- `run(name, command, root, keep, shell=False, env=None) -> Check`. The kept file is `$ <command>`, `exit <code>`, a blank line and the output, on every platform.
- The line of *Scope* item 2 opens `seal gate: `. It names each word and the character the reading stopped at. A case pins its text, on stderr and inside the refusal.
- `seal/config.json`: the `Broad gate` value of *Scope* item 9.
