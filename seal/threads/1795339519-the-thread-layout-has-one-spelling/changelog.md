### Changed

- **Every script reads a thread's file names from `lib/optin.py` and its round records through `lib/routing.py` (#1567).** `broad_gate.py`, `chain_check.py`, `seal_stamp.py`, `settle.py`, `rule_changes.py`, `pact_check.py`, `session_cost.py` and `unverified_check.py` each spelt names such as `trail/gate.md`, `frame/design.md`, `pr.md`, `routing.md` or `threads` again, and `broad_gate.py` and `seal_stamp.py` each held a pattern of their own for `round-N.md`. A case held one of the copies equal to another. Now each script reads the one module, and the case goes with the copies. In a whole plugin, no command's output or exit code changes. A plugin copy without `lib/routing.py` now ends `seal gate --record` at exit 2 with `lib/sibling.py`'s sentence when it counts the round records, as it already did for the other modules under `lib/`.
- **`seal_stamp.py#quote` is the one quoting of a path for a person's shell, and both `plugin_version` functions read the manifest through `lib/core.py#manifest` (#1567).** `broad_gate.py` kept a second copy of `quote`, which nothing had called since #846.
