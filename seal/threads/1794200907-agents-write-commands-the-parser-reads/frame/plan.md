The chosen approach's failure scenario, six months out: Claude Code changes which forms its parser holds for a person. It may start to ask about `$(cat list)`, or stop accepting `"${VAR:?}"`. Rule 21's examples then teach a form that prompts, and nothing in the tree notices, because no check reads an agent's command (`frame/design.md` G2). What limits the damage is the rule's own wording: it states the aim, a command the parser reads, and gives the forms as examples, so an agent that meets the prompt has the aim to rewrite against. A second scenario is that agents do not follow a rule they hold in text. The prompts then recur, and the reading `frame/questions.md` Q1 asks for is what shows it.
