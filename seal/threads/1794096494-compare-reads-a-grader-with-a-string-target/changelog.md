### Fixed

- **`evals/scripts/noninferiority.py compare` stopped on a traceback for every crafter side, because `reads_record` read a grader's target as a mapping and the crafter's `shape-no-probe-left` grader targets the string `files`; such a target now names no round record, and the grader keeps the result the eval recorded (#1421).** `reads_record` decides which `truth-` graders `compare` grades again from the findings of a run's round record. It called `.get("path")` on `config.target`, and `claude plugin eval` also takes `target: 'files'`, which searches every file of the fixture. Five crafter cases hold that grader, so `compare` raised `AttributeError: 'str' object has no attribute 'get'` on every crafter side, and the narrowed verdict of #1254 never read one. `reads_record` now reads a path only from a target that is a mapping, and reads a target of any other value as reading no round record. A side holding such a grader is read, its record is written and its `Verdict:` line is printed. `regrade` reaches the same reader at its last step, after it has written its output file, so on such a side it wrote the file and then raised; it now reads the side there as `compare` does. `evals/` is not in the archive the plugin ships from, so no verdict, output or instruction the installed plugin gives changes. The plugin's version moves from 0.34.0 to 0.34.1 in `.claude-plugin/plugin.json`.
