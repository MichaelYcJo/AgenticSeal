### Changed

- **The suite reads a `contract rule <N>` citation in every tracked text file, and across a `#` comment marker (#1127).** The case that fails on a citation of a contract rule that does not exist read only six trees, `CONTRIBUTING.md` and five file extensions, so a citation in `CLAUDE.md`, a workflow or a `.yml` template was read by nothing. It also missed a citation wrapped across two `#` comment lines. The contract-rule cases now live in `tests/behaviour/test_a_cited_section_stands_in_its_file.py` beside the section-citation case, and both read one corpus: every tracked file outside the records that decodes as UTF-8, with `#` comment markers dropped in every file that is not Markdown. A `#` at the start of a Markdown line is a heading and is not dropped, and the `REM` and `::` comments of `bin/*.cmd` are not read across.
