### Changed

- **The suite checks a citation of any file's section, not only one of `skills/implement/SKILL.md` (#1043).** A file cites another file's section as the backticked path followed by the section's text in italics. Before, one case read such citations, and only those naming `skills/implement/SKILL.md`. A heading renamed in any other file left its citations pointing at nothing while the suite stayed green. `tests/behaviour/test_a_cited_section_stands_in_its_file.py` now reads every citation in the tracked text files outside the records. That includes the possessive form, a skill named by its name, a citation wrapped across lines, and one in a Python comment or split across adjacent string literals. It fails on any citation whose file has no heading or bold rule lead that equals the cited text, or that begins with it and continues with a character other than a letter or a digit. Matching is case-sensitive. A citation in a file of the policy root, `docs/` here, still passes when a pending `## Rule changes` item corrects it, because a pull request does not edit that root. The case prints a warning naming the work item until the settle writes the correction. A pull request that renames a heading cited anywhere else must correct the citations in the same pull request.
- **`skills/writing-style/SKILL.md` names the bold sentence that opens a rule as a section another file can cite (#1043).** The rule on citing another file's section says the italic text is that file's heading or the bold sentence that opens one of its rules. Its `check:` line names the new case.

### Fixed

- **Three citations named sections that do not exist (#1043).** `.github/scripts/gather_changelog.py` cited a section of `docs/the-record-layout.md` by the script's own bold phrase. It now names the rule it meant, *Whether a line is live is asked by what the line does*. `skills/verify/scripts/mutation_check.py` cited `agents/crafter.md`'s rule in lowercase, and now takes the rule's capital. A comment in `tests/behaviour/test_one_word_one_meaning.py` cited a section #975 removed. It now cites the section as the commit before the removal held it, `f6ae6db6:docs/the-broad-gate.md`.
