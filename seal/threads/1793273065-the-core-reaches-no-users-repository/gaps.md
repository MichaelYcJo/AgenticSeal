# Closing memo: 1793273065-the-core-reaches-no-users-repository

## Why this work exists

The plugin's core stood only in this repository's `CLAUDE.md`, so no agent or session in a plugin user's repository read it; it becomes `skills/core/SKILL.md`, which every agent preloads and the preset block imports.

## Not done

On a machine with the new block installed, every agent reads the core twice: once through its `skills:` list and once through `~/.claude/CLAUDE.md`'s import, which the harness adds to every spawn (#292). The second read costs about 2,100 tokens per agent spawn at 3.2 B/token; the exact bytes are `trail/phases/phase-3.md`'s, measured at its commit, and the pull request body gives them at the broad gate's HEAD. Both paths stay. The issue's Done-when names `skills:` as the agents' path, and that path is the only one that reaches a user who never ran the installer. A user-scope import cannot be made conditional on who reads it. The orchestrator decided this on 2026-10-29 against the issue's constraint *No session reads the core twice*, which names sessions. #1183's review weighs it, because a `SessionStart` hook may not reach a subagent at all (unverified).
