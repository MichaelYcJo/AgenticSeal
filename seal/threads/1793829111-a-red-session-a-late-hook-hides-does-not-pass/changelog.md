### Fixed

- **`seal gate` passed a suite with a failing test where something after pytest's run loop turned the row's exit into 0, so the sealer could guarantee a red suite; the gate now fails it (#1301).** A conftest `pytest_sessionfinish` hook that runs after the gate's recorder and calls `pytest.exit()` with a return code of 0 is one such act. A hook that sets `session.exitstatus = 0`, a `pytest_unconfigure` hook that calls `os._exit(0)`, and a `Broad gate` row that ends `; true`, `|| true` or a pipe are others. In each, the row exits 0 over a test that failed. The gate printed `BROAD GATE PASSED` with `1 failed` among the suite's counts and wrote `trail/gate.md`, which the sealer reads as a passed broad run. The recorder's `end` line already held the session's real exit, 1, because pytest hands every `pytest_sessionfinish` hook the exit its run loop gave, and nothing after the loop changes that line. Now the gate fails the suite wherever a pytest session at `HEAD` did not pass by its own record, whatever the row's exit. A session passed where its `end` line names no stop and reads exit 0 or 5. The run exits 1, prints `BROAD GATE FAILED`, and writes no `trail/gate.md`. The failing file is compared at the base and listed with its word, as on any failing suite. Under the suite's own lines, the failure form now says that the row exited 0, and that the session either stopped part-way or ended with exit 1 while a later hook or a part of the row after pytest chose the row's exit. A suite whose sessions all passed, a late hook's included, passes as before. A row that masks a red pytest, or runs it a second time over a failure, now fails at the gate where it passed before. The late hook is no longer named as a stop out of the record's reach. The one stop left there is a stop raised before the recorder writes a session's first line, such as one in a conftest's `pytest_configure`. `templates/setup/config.md` *The criterion for choosing a value*, rule 3, states the new behaviour. The `;` row and the pipe row of its *Everything else stays legal* list now say that a pytest session the row runs that did not pass still fails the suite. The rule is in force from this merge through the work item's rule changes. The settle after the release writes it into `docs/running/the-broad-gate.md` *One act, one owner, and the owner is the orchestrator*.
