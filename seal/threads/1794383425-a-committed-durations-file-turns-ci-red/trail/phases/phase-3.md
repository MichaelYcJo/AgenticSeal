**Decisions.**

- **Each reader that reads a `run:` script for a command reads it through `tests/conftest.py#code_lines`.** The old readers dropped every line that opened with `#`, YAML's and the shell's alike. The parser drops YAML's comments, and `code_lines` drops the shell's. This was judged against *Scope* item 4, which keeps `code_line` for that reading.
- **The gate's base reader reads a `BASE:` under the workflow's, a job's or a step's `env:`, in the order the file writes them, and a flag only in a step's script.** The old reader took a `BASE:` under any `env:`, so the workflow-level and job-level readings keep its reach. It also took a `--baseline` from any code line, a `with:` value among them. The new reader takes one from a `run:` script alone, which is where the gate's question lives. `WORKFLOW_SHAPES` became step mappings, because the old fragments were not YAML documents. `MISLEADING_WORKFLOW` is loaded from a file under `tmp_path`, because `load` takes a path. The fixture gained a shell comment on its own line and one after a command, and a `BASE:` under the workflow's and a job's `env:`, so each branch of the reader has a case.
- **No step helper was added to `tests/workflows.py`.** `frame/design.md` *Data & interfaces* fixes that module as `load(path)`. Each module finds its step with a comprehension of its own, of two to five lines.
- **`hygiene.yml`'s claims-check case reads every step's script whole for the body's expression.** The old assertion read only the text after the last `run:` in the file.
- **`test_release_hygiene.py#matrix_pythons` reads the `python` of each `include:` entry.** The old regex read the same values, the quoted `python: "x.y"` lines. Its first name, `tested_pythons`, was collected by pytest as a case and was renamed before the commit.
- **The teammate flow runs each step's script as the parser returns it.** The old reader took `run: |` blocks alone and dropped their comment lines. The template's three scripts are all block scalars, and bash ignores a comment.
- **A removal the frame did not name.** `tests/text/test_the_rules_claude_md_names_have_one_home.py#LINKED` and `#CARRIERS` held `tests/test_conftest.py` because its fixture's comment cited `CONTRIBUTING.md` *House rules*, *No real identifiers*. The fixture went, and the case refused the file for naming no home. Both entries went, and a count in the comment above `LINKED` went with them (`0fc6e80a5`). This was judged against contract rule 19.
