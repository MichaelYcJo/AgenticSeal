### Fixed

- **A spawn row with a long agent name stays under its headers in `seal cost --spawns` (#712).** A spawn-cycle row's label is cut from the right to the 30-character column that the per-segment table already uses, with no mark, so each cell of the row ends where its header ends. Before, a label longer than the column pushed every cell of its row to the right, and a reader took one column's number for the next one's. The label is `cycle N  ` and the `subagent_type` together, so for a single-digit cycle any name longer than 21 characters did it. `seal cost --json` keeps `subagent_type` whole, and that is where a reader finds the full name of a cut row.
- **Each line under *what each cycle spawned* has one space between the label and the description (#712).** A label cut to the full column ran straight into the description. Each description after a label that fit the column now starts one column further right than before, and one after a label longer than the column now starts at that same column.
