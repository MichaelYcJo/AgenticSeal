## Data & interfaces

No interface changes. The work writes, under `seal/threads/1793528484-the-process-measured-on-0-27-2/`: `trail/phases/phase-1.md` to `phase-3.md`, `gaps.md` and `changelog.md`. Each phase record holds `## What this phase found`, and under it the head named in *Scope* item 1, a `### The measures` table with one row per measure (the measure, the before with its source, the after with its source, and whether the before reproduced), a `### Commands` section with each command whole, and, in phase 3, `### The reading` and `### Drafts`.

The probes each phase writes, a script that reads transcripts among them, are written and run under the session's scratch directory, `<scratchpad>/1793528484-the-process-measured-on-0-27-2/`, and the record carries each one's text whole under `### Commands`, so it can be re-run without the scratch directory. A script of the repository, such as `finding_counts.py`, runs from a `git clone --no-local` made in that directory.
