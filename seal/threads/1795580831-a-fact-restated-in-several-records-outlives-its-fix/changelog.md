### Added

- **A `PostToolUse` hook names, after an edit of a work item's record, each place in the item's records that still holds the words the edit replaced (#1612).** A work item's records restate one fact in several files: the frame, `gaps.md`, `changelog.md` and `pr.md`. A fix that changed the fact in one of them left the others, and the next round found each copy as a finding. In a repository that runs the chain, 45 of the 122 `location:` lines its rounds 2 and later had written, counted on 2026-11-25, named two or more records at once. Now `hooks/edit-leaves-copies.py` runs after each `Edit` call of a session or a subagent. Where the edited file is a `.md` record of a work item under a marked root, outside `trail/` and other than `guarantee.md`, it takes each span of `old_string` the edit changed, with three words on each side read from the edited file around the place `new_string` now stands, so a change at an end of `old_string` keeps the words beside it, and keeps a span of 6 words and 30 characters or more. It looks for each span, with whitespace collapsed, in the item's records outside `trail/` and other than `guarantee.md`, the edited file among them. Where a link stands anywhere from the root down to the edited file, it opens no record and prints nothing: it checks the root before it opens the root's `README.md`, and the root's `threads/`, the work item's directory and each component under it down to the edited file before it opens a record. It reads no record that is a link. It names each place with its path and line in the context of whoever made the edit, and says that a place stating the changed fact is rewritten in place or cites the record that holds it (contract rule 19), and that a place stating another fact stays. It reads words, so a copy in other words is not found, and a deletion at an end of `old_string`, whose words the file no longer places, keeps the words of `old_string` alone and can print nothing. It refuses nothing, writes nothing, starts no process, reaches no network, and prints nothing wherever its input, the path, the root or a record cannot be read. A session loads it at its next start after the update.

### Changed

- **`seal pr-body` refuses a quote of `pr.md` whose words no longer stand in the file it names (#1612).** A quote is now one line in one spelling, ``- "<the sentence>" (`<path>` <coordinate>)``, where `<path>` is the record's path under the work item's directory. `seal pr-body`, its `--check` form and the pull request's check each read every such line. Each refuses at `pr.md`'s line where the path names no file of the work item's directory, where that file cannot be read as UTF-8 text, or where the file, with runs of whitespace collapsed, does not hold the quote's words. A line that holds `" (` before a backtick outside the form is named as not read, on the line opening `seal pr-body:`, and decides nothing. What the coordinate after the path names stays the rounds' and the sealer's reading. Before, a quote whose source a fix pass had changed stood until a round found it.
- **A round finding that says a sentence states a fact wrongly carries the command that lists each place stating that fact, and the fix pass runs it again (#1612).** `skills/code-review/SKILL.md` *A paste-ready fix reaches every statement of the fact it repairs, or names where it stops* has the finding carry the command, such as a `git grep -n -F` on the fact's words, on its `evidence:` line as `executed`, and its grounds say what it printed and that a search on words is a sample. `skills/implement/fix-pass.md` *The close blocks, last* has the fix pass run it again after its last fix commit, and the close block's `answer:` name each place it still prints with why that place stands, or say that it prints none. Before, a finding named one place, and its fix left the others.
- **The proofer no longer reads each quote of `pr.md` word for word at its source, and the orchestrator rewrites a stale quote where `seal pr-body` refuses it or where a hand-back or the hook names it (#1612).** `agents/proofer.md` drops the sentence, since `seal pr-body` reads the same words exactly. `skills/code-review/orchestration.md` *Orchestrator: the pull request opens once the sealer seals* gives the one spelling of a quote, and keeps the orchestrator's rewrite of each rendering of `pr.<lang>.md` before the next round.
- **The count of the plugin's hooks moves to four in each README edition (#1612).** `README.md` *What runs on your machine*, `README.ko.md` *내 컴퓨터에서 도는 것*, `SECURITY.md` and `CONTRIBUTING.md` *House rules* name the `PostToolUse` hook beside the other three.

`docs/forms/the-round-record.md` *The round record* and `docs/running/what-a-script-gates.md` *The checks* state the listing command, the quote check and the hook from the settle after this release, which writes them from the work item's `## Rule changes`.
