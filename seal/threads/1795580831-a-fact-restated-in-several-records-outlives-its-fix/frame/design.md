## Data & interfaces

**The quote form, read in `pr.md` alone.** A quote is one line: `- "`, the quote, `" (`, a backticked path, then any text, then `)` at the line's end. The quote runs to the last `" (` before a backtick on the line, and a `"` inside it is itself, with no escape. The path is relative to the work item's directory, as every quote at `aa32e8473` writes it (G9). The quote stands where its text, with each run of whitespace made one space and the ends trimmed, is a substring of the file's text read the same way. What follows the path, the heading, row or line the coordinate names, is not read. A quote of `changelog.md`, which the rule `skills/code-review/orchestration.md` *Orchestrator: the pull request opens once the sealer seals* holds against, is checked like any other, and the rule stays the rounds'.

**The refusals**, each at `pr.md`'s line, in the shape `#read_own`'s refusals take: the path names no file of the work item's directory, an absolute path or one that leaves the directory among them; the file cannot be read as UTF-8 text; the file does not hold the quote's words. The note for a line not read joins the other notes on the line opening `seal pr-body:`.

**The hook.** It reads the `PostToolUse` payload from stdin, and of it `tool_name`, which is `Edit`, and `tool_input`'s `file_path`, `old_string` and `new_string`.

- It reads on where `file_path` stands at `<root>/threads/<id>/<file>`, where `<root>/README.md` opens with `lib/optin.py#MARKER`, and `<file>` ends in `.md`, stands outside `trail/` and is not `guarantee.md`. The work item's records it then searches are the `.md` files of `<root>/threads/<id>/` outside `trail/` and other than `guarantee.md`, the edited file among them, as they stand after the edit. `trail/` and `guarantee.md` are records of what a party read and did, which quote what they read.
- The words the edit replaced are each span of `old_string` that differs from `new_string`, compared word by word, with three words on each side; a span kept is 6 words and 30 characters or more, as G7 measured. An insertion's span is the three words on each side of the point.
- A place is a file of that set whose text, whitespace collapsed, holds such a span. It prints `{"hookSpecificOutput": {"hookEventName": "PostToolUse", "additionalContext": <text>}}`, where the text names each place by its path under the work item's directory and its line, with the words that stand there, and says that a place stating the fact the edit changed is rewritten in place or cites the record that holds it (contract rule 19), and that a place stating another fact stays. The text stays under the 10,000 characters of G15.
- It prints nothing where no place is found, and where the payload, the path, the root or a file cannot be read. It writes nothing, starts no process and reaches no network. Its `__main__` turns every raise into exit 0, as G18's does, and the command ends with `|| exit 0`. Its docstring holds these edge cases and its failure direction: a wrong silence costs a copy the next round finds, and a wrong print costs the writer one look.
