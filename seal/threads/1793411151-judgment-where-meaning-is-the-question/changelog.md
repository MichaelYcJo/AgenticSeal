### Added

- **`seal settle`'s dry run prints the judgments each released run made, grouped by the document each stands on (#1167).** The orchestrator now writes each judgment it makes in a run to a new last section of `frame/plan.md`, `## Judgments of the run`: going on past the third round or stopping, a regression's route, a leftover's home, and a decision folded into the frame. Each row holds the date, the judgment, its grounds and the document it was judged against. The dry run reads every released plan's table through `hooks/lib/config.py#gfm_table` and prints the rows grouped by the `Judged against` cell, with each work item's round count beside it. A plan with no such section prints nothing. A heading whose letters, case folded, are the section's and that is not it, such as `## Judgments of the Run`, is named as not read at its line, and so is a section whose table is not under the exact header. A work item whose `trail/rounds` is not a directory the dry run can list is named in place of a round count. `--apply` removes the plans, so the settle is the one reading the rows get; `skills/settle/SKILL.md` tells the settling session to rewrite a section where one kind of judgment recurs or keeps costing rounds.

### Changed

- **A check reads each form in one spelling and names what it did not read, and no longer refuses a line for its spelling (#1167, #1170, #1121, #1125).** `skills/core/SKILL.md` *The rule a mechanism is kept against* says a script holds a gate only on a fact it reads exactly, names as not read a line or a file that looks like one of its form's and is not one, and carries no list of the spellings a label is written in. Whether such a line meant the label is the reading agent's judgment. `skills/writing-style/SKILL.md` says the same for a writer, and `CONTRIBUTING.md` *What a change to a gate must carry* asks a change to a gate to name what it reads.
- **The core lists the five invariants that hold the chain, each with what it protects and the mechanism that holds it.** *Judgment is not licence to skip a party* holds them as a table in place of a list.
- **`chain_check.py` reads each label of a round record and of a guarantee in one spelling.** A line that opens like a label and is not it, such as `Verdict: open`, is printed as `path:line  not read: <why>`, which CI renders as a notice, and changes no exit code. A finding that then lacks a required line is refused for lacking it, as before. A file under `trail/rounds/` whose name is no `round-N.md` is named as not read. The `Old spelling` table is no longer loaded. A misspelt `original:` line in a guarantee no longer counts as present.
- **`seal pact` grades the anchor table only under the exact header `| Pact | Clause | Hash |`.** A table under a near header, such as `| pact | clause | hash |`, is named at its line with the exact header to write, and none of its rows is graded.
- **A heading near `## Rule changes`, such as `## Rule Changes`, is another section.** The check names it and passes, and `seal settle` lists the design among those to read whole.
- **`seal rules --check` names a near `check:` line at exit 0**, where it refused it before. A target wrapped onto the next line is not read.
- **`seal unverified` reads `closed` and the no-change block in their one spelling.** A row opening `closed.` is open, and a near no-change block is named.
- **`seal deferrals` reads no trigger.** It names each CI file and hook holding a runner command, with the command it read, and says the trigger is the reader's to open; it exits 1 only where no CI file holds a runner. The outcomes `too late` and `wrong trigger` are gone, and with them the misreadings of a tab-indented `on:` block and a U+2028 inside a comment.
- **The round cap and a second regression read as judgments.** `skills/code-review/orchestration.md` keeps three finding rounds since the last design change as the point where the orchestrator weighs going on, with the signals of a run that is not converging and what going on and stopping cost. The extension line the proofer wrote goes; no round record ever carried one. A second regression on one unit is routed to the framer unless the orchestrator writes why the frame holds.
