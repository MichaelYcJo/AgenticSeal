### Changed

- **`seal payload` gives one token figure, an estimate from the bytes, and its README row names the three flags it takes (#1484).** Every row, the session's and each agent's, is its bytes over an assumed 3.2 bytes per token, and every total is the sum of the rows above it, all under one basis that reads `estimated (3.2 B/token, an assumed ratio)`. The session's rows no longer say that no transcript calibrates a session, and the agents' rows no longer say that nothing calibrated them. The `CLAUDE.md` pair line ends "inside every agent's prefix" and no longer names a baseline. The `seal payload` row of `README.md` and `README.ko.md` names `--json`, `--agent <name>` and `--root <dir>`, and says the tokens are estimated from the bytes. `.github/scripts/release_report.py` prints the same table as before, and calls the meter's `composition` with four arguments.

### Removed

- **`seal payload --calibrate`, `--baseline-agent`, `--baseline` and `--sections`, with the code only they reached (#1484).** The calibration from a session transcript, the comparison against an earlier run with its `## Delta` section, and the split of each file at its headings go. No document or workflow named any of the four flags, and each is now refused with argparse's usage error and exit 2. The JSON output loses `ratios`, `baseline`, `calibrated_from`, `calibration` and `delta` at its top, `prefix` in an agent and `sections` in a row. Measuring an agent's tokens again is a manual act: read a spawn's first `usage` block in its subagent transcript and subtract a baseline spawn's.
- **Five symbols that no shipped code called (#1484).** `stray_rounds` in `lib/routing.py`, `parity_config` in `lib/optin.py`, `closed_fence_lines` in `lib/lines.py` and `DISC_COLOURS` in `skills/verify/scripts/seal_stamp.py` go with their cases and with the docstring sentences, comments and rider that stated them. The rider on `repo_root` counted the `git` calls of a commit gate that #1027 removed. `strip_ansi` leaves `seal_stamp.py` for `tests/skills/test_seal_stamp.py`, the one file whose cases call it. The case in `tests/text/test_a_rider_reaches_its_file.py` that held a rider at `lib/optin.py` goes with that rider.
