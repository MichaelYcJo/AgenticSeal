A rule that reaches a party through its definition, or through the `skills:` list of its definition, reaches no orchestrator that does that party's work. And the account of a read was asked for as a description, which a writer fills with the rule's own words, where the tree offered no command that prints what the rule asks to be read.

## Data & interfaces

**`seal range`.**

```
seal range <item> --from <commit> --out <file>
```

- `<item>` is the work item's directory. `--from` names the commit the builder's range starts after: HEAD as the phase began, or the commit a round's `target:` names. `--out` names the file the command writes and replaces.
- The file opens with the line `range: <from>..<HEAD>`, both as full hashes. Then, for each path `git diff <from>..HEAD` changes: a `.md` path has each hunk printed with every line of HEAD's file from the blank line, or the file's start, before the hunk's first changed line to the blank line, or the file's end, after its last; every other text path is printed as `git diff -W` prints it, each hunk widened to that same blank-line bound where `-W` stopped short of it (*Scope* item 10); a binary path, a deleted path and a path whose entry is a submodule's commit on either side of the range (*Scope* item 11) are named and not printed, and a rename is read as its old path deleted and its new path added. Then come `routing.md`, `frame/design.md`, `frame/plan.md`, `frame/questions.md`, `gaps.md` and `changelog.md` of `<item>`, each whole as HEAD holds it, under a line naming its path, and one HEAD does not hold is named as absent. Where the root is in local mode, no commit holds the records, so each is printed as it stands on disk, under a line that says the root is local. No line is cut or wrapped.
- It prints to standard output one summary: the range, the number of lines written and the file's path, each path it named and did not print, and each tracked path with an uncommitted change, which it names as not read.
- Exit 0: the file is written. Exit 2: an argument is missing, `<item>` is not a work item's directory under a marked root, `--from` does not resolve or is not an ancestor of HEAD, git failed, or `--out` cannot be written; no file is written. It has no other exit, because it judges nothing.
- It starts git through `lib/gitcmd.py#git`, takes each path from `-z` output, writes nothing but `--out`, reads no transcript, and reaches no network, as `docs/running/what-a-script-gates.md` *Which gate a script holds* asks of a script that reads git.
- The script's docstring holds its edge cases. `skills/implement/SKILL.md` holds the one command line a builder types.

**A wording for the account's rule of *Scope* item 2**, which the build may refine without changing what it binds:

> **The account of that read quotes its commands and describes no read in other words.** It names the commit the read ran at. It quotes, as typed, the `seal range` line with the line the command printed, each command that printed a correction's hunk after the commit that made the correction, and each `git grep` of the sample. Then it gives each statement the read leaves standing, with why, and where the part the sample did not reach stands. The crafter writes the account in its hand-back. The orchestrator writes it in `trail/phases/phase-N.md` `## What this phase found` for a phase, which it commits last, and for a fix pass where `skills/implement/fix-pass.md` *The narrow set, then the read of the range* puts it.

No schema, hook, configuration key or record field changes. The new units are the script, with its constants `GITLINK` and `SUBMODULE` of *Scope* item 11, its test module, the `range` entry of `TOOLS`, and the bold leads **The builder is the party that builds a phase or makes a fix pass**, **The build holds to the request**, **Before the builder closes a phase or a fix pass, its range and the work item's records are read whole against HEAD** and **The account of that read quotes its commands and describes no read in other words** in `skills/implement/SKILL.md`. The file gains no heading, so each citation of its sections by heading stays.
