### Changed

- **The suite cuts a section of a document one way (#1580).** `tests/conftest.py#section(text, heading)` finds the heading line among the headings `lib/lines.py` reads, so a heading quoted inside a fenced block is no heading. It returns the body up to the next heading of the same level or above, without the heading line. Nine test modules that defined a `section` of their own, and the helpers of other names that cut one section by its heading, read through it. No test module defines its own `section`, `read` or `flat`. `tests/skills/test_coordinates.py#section`, which asks the kernel's `heading_path`, is `regions`, and `tests/skills/test_broad_gate.py#flat` is `unquoted_flat`, for the block-quote marker it drops.
- **The cases that spell a value the code defines read it from the code.** These are the routing answers, the routing file's path, the trailer of a commit that records no work item, a fix pass's two close verdicts, a verifying round's three line keywords, the broad gate's words beside a failing file, and the exit codes and states of the pull request wait. The cases take them from `lib/routing.py`, `chain_check.py`, `lib/fields.py`, `broad_gate.py` and `pr_wait.py`. A renamed constant now fails the case at the attribute, which names the code.
- **The eval cases are read by the YAML parser.** `tests/workflows.py#parse` reads a YAML text the way `load` reads a workflow file, every scalar a string. `#front_matter` reads the lines between a grader's first two `---` lines. `tests/behaviour/test_evals_layout.py` reads each `case.yaml` and grader through them, and so does `tests/evals/test_rule_cases.py`. A sealer case's bound on the broad run is judged by what its `input_match` finds, so a pattern that finds `seal gate --base` in another spelling no longer reads as a gap.
- **The measurement that chose the 15-word window stands over `skills/settle/scripts/passages.py#WINDOW`.** Its comment holds both ends, the 10-word longest run a kept application shared and the 25-word smallest real copy, with the pairs that gave them. The paste test's docstring and `tests/skills/test_passages.py` cite it.

### Removed

- **The 806,241-token pin and its derivation comment.** Row 18 of `tests/text/test_the_rules_have_one_owner.py#RULES` asserted only that `skills/code-review/orchestration.md` spells the number, which no code reads. That section, *Orchestrator: a phase is a fresh crafter, and a fix pass resumes the implementer*, is the number's one home. #1579's entry in this release says the comment over that row records the derivation. The comment is gone, and the derivation, #945's S5 measurement from the 0.22.0 run, stands in git history: `git log -S'806,241'` finds the commit that removed it.
- **The snapshot of the writing rules' `check:` line.** `WRITING_RULE_CHECKS` copied the line byte for byte. The case now counts one `check:` line, and `seal rules --check` over the tree resolves its targets.
- **The moved-rule window cases and their stored measurements.** `LONGEST_KEPT_APPLICATION`, `SMALLEST_REAL_DUPLICATION` and the cases of `tests/text/test_a_moved_rule_leaves_its_definition.py` that cut the contract into rules and searched each agent definition for a shared run. `tests/text/test_no_passage_is_pasted_into_a_second_file.py` reads every pair of the contract and a definition. Its docstring now states that a passage shorter than the window is not caught.
- **The second case of the routing vocabulary.** `tests/text/test_review_axes.py#test_the_routing_section_holds_the_answers_and_the_shape`, whose facts `tests/behaviour/test_waiver_decided_at_start.py` holds, and that module's text search of `lib/routing.py` for each answer.
- **The hand readers of eval YAML.** `top_level_keys` and `block_keys` of `tests/behaviour/test_evals_layout.py`, which read keys by column, and the regular expressions over a grader's YAML spelling. The layout case's refusal of a sealer grader that reads the `Broad gate` cell goes too: the sealer stopped writing that cell at 0.22.0 (#923), and the generator is the one writer of the sealer cases.
- **`evals/scripts/behaviour.py#scalar`, `#grader_from` and `SCALAR`.** Only tests called them. `tests/evals/test_behaviour.py` loses their cases and keeps the census over the script.
- **Two cases whose fact another case holds.** `tests/behaviour/test_the_contributor_has_a_procedure.py#test_the_check_can_fail` held that the module's own `section` refused a guide without the heading. `tests/test_conftest.py#Test_section` holds that refusal for the shared helper. The emptiness assertion of `tests/skills/test_chain_check.py#template_section` is held by `tests/behaviour/test_a_phase_hands_the_next_one_a_record.py#test_the_spec_template_carries_the_rule_changes_section_above_removes`.
