### Removed

- **The behaviour suite no longer reports the proofer's recall or false-finding rate (#1487).** The verdict `evals/scripts/noninferiority.py compare` writes has read only the shape and reach graders since #1356, and the owner decided to stop reporting the two rates. The record `compare` writes drops the `Baseline report rows`, `Baseline false rows`, `New report rows` and `New false rows` rows and both `tokens per true find` rows. Its `## Graders` table still lists every grader the eval graded, truth graders among them, and computes no rate from them. Spend, tokens, tool calls, wall seconds and preload bytes are written as before. A record written before this change still passes `check` and `model`, which read past the removed rows.
- **`noninferiority.py regrade` is gone (#1487).** It re-graded a paid side against a new truth grader, for recall alone. A maintainer who ran it gets argparse's exit 2.
- **A side no longer keeps the round record the proofer's session printed (#1487).** `run` writes no `report_text` on a run, and the trace that held it stays under `<out>.raw/`. A side written before is still read, and the key is ignored. `compare` now accepts a side taken before #986, which it refused for lacking `report_text`.
- **The replay and seeded case generators are gone (#1487).** `evals/scripts/replay_targets.py`, `evals/scripts/seed_defects.py` and their input `evals/scripts/recurred_truths.json` go with their tests, as does the case that no two truths of a proofer case accept one location, which guarded recall's count. The eight `proofer/replay-*` and `proofer/seeded-*` cases stay as committed, as records of a review at a recorded commit, and no script writes them again. `evals/scripts/rule_cases.py` writes the one recurred truth, `truth-shout-twice-uncovered` of `proofer/rule-proofer-one-finding`, itself, and every rule case it writes stays byte for byte as committed.

### Changed

- **The check that no behaviour case tells the agent it is evaluated passes over a replay or seeded case whole (#1487).** It exempted the values the generators copied into those cases by rendering the generators' own text. With the generators gone, `tests/text/test_no_case_tells_the_agent_it_is_evaluated.py` reads which cases are records through `tests/censuses.py#RECORDED_CASE`, the pattern the old-names census already passes over, and reads every rule case as before.
