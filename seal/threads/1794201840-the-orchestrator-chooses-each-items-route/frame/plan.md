# Implementation Plan: the orchestrator chooses each item's route (#1459)

## Technical context

The tree as read at `e1067476`.

The work is prose that an orchestrator, the framer and the sealer read, plus the pins on it. No code under `lib/` or any `scripts/` directory changes. `lib/routing.py#parse` reads a declaration's table rows alone, and no row holds a question 1 label, so neither a chosen declaration nor the renamed labels reach a parser (`frame/design.md` G6, G7). The trailer keeps its value, so `chain_check.py#NO_WORK_ITEM` and its cases stand (G8, *Scope* item 12).

The routing section is `skills/implement/orchestration.md:250-494`. *Question 1* is at `:272-300`: its table takes the four modes in the owner's order. *Question 2* and *The ceiling* are at `:302-328`. *What the answer writes* is at `:330-494`. The new subsection goes after *What the answer writes*, so the person-facing tables stay together above it.

The pins are in `tests/behaviour/test_waiver_decided_at_start.py` (G25). `tests/text/test_review_axes.py:255` pins a copy of the shape sentence, which changes with it to "only under `manual`". Two cases read text shared across files and are in each phase's set. `tests/text/test_no_passage_is_pasted_into_a_second_file.py` refuses a passage of fifteen words or more in two files, so a README line and a Description cell must not share one. `tests/behaviour/test_both_editions_carry_the_same_folds.py` reads the two READMEs together.

The failure scenario of the chosen approach, six months on: the orchestrator takes `direct` for prose changes whose defects show only when an agent misreads them in a later run. The check prints each such commit at its own pull request, and nobody reads that list. The loop that would show a loose rule is the settle's step 5 sentence (*Scope* item 6), and it depends on the settling session reading the release's `no work item` commits. A settle that skips the sentence leaves the routing guidance unrevised however many defects the choices let through. The rule that touching a gate, a hook or a check script weighs against `direct` bounds that cost. A defect in plain prose is cheap to find and revert. A defect in a gate is not.
