### Changed

- **The docstrings and comments of the plugin's scripts say what the code does now and why, and no longer tell how it came to be (#1485).** This covers every Python file under `lib/`, `hooks/`, `.github/scripts/` and `skills/*/scripts/`, 50 files, and the comments of `bin/test`. Sentences about a former state went: what the code, a reader or a document used to do, what replaced what, and what a review found before a change. The issue, review round or finding a present fact came from went too, and so did the date of a measurement of this code, and every pointer into a work item's records, which leave the tree after their release. Where such a sentence held the only statement of why a branch exists, the reason is now written in the present tense in the same docstring or comment. Five kinds of sentence stay. A `#N` or a date that is a sample of a format a script reads or writes stays, such as `Closes #1`. "Measured" stays where it names what the code measures now. An observed behaviour or an evidence count a constant rests on stays without its date and issue, with the tool's version where the tool has one. An owner's decision keeps its issue as its one coordinate. A compatibility branch names the older shape it still reads. `git blame` leads from any line to the pull request and its issue.
- **No code, string constant or printed message of those files changed (#1485).** A comparison of each edited file's syntax tree, with its docstrings taken out, found no difference over each phase's range. Text a person reads at a terminal stays as it was, the help texts and refusals that carry an issue number among them. One test assertion went with the sentence it pinned: `tests/skills/test_session_cost.py` no longer requires `token_thirds`' docstring to name `#192`, the issue its class came from, and its other three assertions stand.
- **Sentences outside the scripts that the rewrite made false, or that stated a fact it corrected, were corrected (#1485).** The comment over the claims step of `.github/workflows/hygiene.yml` now says `close_issues_on_release.py`'s one-number rule stands over `KEYWORDS`. The comment over an assert in `tests/github/test_label_merged_on_release_branch.py` now says why the assert reads the call and not the bare name, without citing a sentence the sibling script no longer holds. Two docstrings in `tests/lib/test_optin.py`, like two of `lib/optin.py`, cited a rider on `repo_root` that does not exist; all four now state the cost directly, a `git` call paid on every gated command.
