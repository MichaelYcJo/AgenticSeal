### Changed

- **`dist` no longer ships the twelve files the plugin directory refused by type while nothing installed read them (#1535).** The directory refuses any file other than Markdown, text, JSON, YAML and five image types from an organization that is not Verified. Besides the plugin's code, the archive of a tag held five `.svg` and five `.ans` drawings under `assets/seals/`, `ruff.toml` and `.gitattributes`. Each is now marked `export-ignore`, so `main` and an install from this repository's marketplace keep them and `dist` does not. Both readmes draw their header emblem from `.claude-plugin/icon.png`, the PNG rendered from `owl.svg`, so the readme the directory shows keeps its image. A census case fails where the archive holds a file of a refused type that is not the plugin's code. The directory still refuses the version for its hooks, `bin/` and scripts (#1420).
