### Changed

- **The proofer's eval cases now rebuild trees the current plugin reads as its records root (#1229).** The eight replay and seeded cases under `evals/behaviour/proofer/` were cut from round records in the layout before 0.23.0, `seal/specs/<item>/rounds/`. Each rebuilt a tree whose `seal/README.md` does not open with the marker the gates look for, so the current plugin did not read that tree's `seal/` as its records root, and the suite measured a tree no user of the current release runs. They are replaced by the eight cases that `evals/scripts/replay_targets.py --count 4` and `evals/scripts/seed_defects.py --count 4` write from round records under `seal/threads/<id>/trail/rounds/`. The replay cases are `replay-1793419351-r4`, `replay-1793457435-r3`, `replay-1793411151-r2` and `replay-1793419350-r2`. The seeded cases are `seeded-bf9efcba`, `seeded-55b66958`, `seeded-ea73e94f` and `seeded-5fd6b88c`. Each regenerates byte for byte with `--case` from the release tags. The suite's replay and seeded cases now hold 13 `truth-` graders where they held 27, one for each replay case. The 10 entries of `evals/scripts/recurred_truths.json` that widened or added truths of two of the old cases leave with them, because the generators stop on an entry whose case is gone. The old cases and those entries stay readable at `v0.27.1`. A proofer comparison now runs both sides from the commit that lands this change, because `noninferiority.py compare` refuses a pair whose suites differ. No recorded side is lost by this, since no side taken before 0.27.0 compares with a later one. Whether the proofer reads a new case's records and writes its record where the prompt says has not been measured: no paid eval run was taken in this release.
