## Technical context

The tree as read at `b9ca37404`.

The work changes one script, `skills/verify/scripts/test_layout.py` (`#_calls` at `:462-492`, `#check` at `:341`, `#main` at `:1198-1302`), its cases in `tests/skills/test_test_layout.py`, the section `CONTRIBUTING.md` *The test layout* (`:216-338`) and the sentence of *What a contribution is asked for* (`:41-44`) that names the tree-wide files, the files of design *The files*, the module files their M cases move into, and every citation of what moves (design *Scope* item 9). It writes no new shipped module and no new module file: every module a case reaches already has its file (design G7).

Five constraints shape the build.

- `seal rules --check` refuses a check line naming a path that is no file (design G8). A phase that deletes or empties a file re-points every line naming it in the same commit, under `docs/` too (design G9). A line #1488's pending operations hold is the one exception (design G10).
- A move is checked by `bin/seal layout --moved`, which passes only where each case's body, fixtures and the names it reads are unchanged (`skills/verify/scripts/test_layout.py`, docstring). So the criterion's ruling of a case is committed before its move, and a phase that rules and moves makes at least two commits, the ruling and then the move, with the move check's base at the ruling commit.
- `bin/seal layout --check` refuses a `Test_<name>` class without an accepting and a refusing case, so a moved case joins a class that has both, or `Test_module`. A case keeps its name, which states the rule it holds, so what the issue names as the cost, finding a rule by a file named after its sentence, is paid only where a file is deleted.
- Seven files of design *The files* hold names other test files import (executed: `git grep -h '^from test_' -- tests`, set against the stems of design *The files*): `tests/behaviour/test_a_cited_section_stands_in_its_file.py`, `test_one_table_walker_reads_what_gfm_renders.py`, `test_release_hygiene.py` and `test_waiver_decided_at_start.py`, and `tests/text/test_no_case_tells_the_agent_it_is_evaluated.py`, `test_the_agent_contract_holds_the_universal_rules.py` and `test_the_record_is_written_in_words.py`. A name that moves, or that stands in a file a phase deletes, moves unchanged to `tests/conftest.py` or to the destination file, as design *Scope* item 5 states, and each importer is re-pointed in the same commit; the move check follows a name into either (`skills/verify/scripts/test_layout.py`, docstring, *names*).
- #1482 changes the module files phases 4 and 5 move cases into (*Overlap with the release*). This branch took `release/v0.37.4` with #1482 in it by the merge `30e82d2f8`, never a rebase, so those phases start on #1482's text.

The phases run in order. Phase 1 changes the reader and the rule the others are judged by. Phase 2 files `tests/text/`, which no sibling's branch touches. Phases 3 to 5 move the M cases of `tests/behaviour/`, one destination area each, so each move check covers the shipped directories of one area. Phases 6 and 7 rule and file what each half of `tests/behaviour/` keeps once its M cases have left. Phase 8 gives the pairs that stood before the build their reason and takes the counts.

The failure scenario of the chosen approach, six months on. A change to `lib/optin.py` breaks the shared root under `agentic-seal/`. The cases that held it ran in a tree-wide file at every phase boundary. They now stand in `tests/skills/test_seal.py` and its neighbours, and a phase that changed only `lib/optin.py` does not run those files, because a test file reads a path only directly or through another test file (`skills/verify/SKILL.md` *A test file reads a path when its cases open it, import it or load it, directly or through another test file.*). The defect then meets the orchestrator's broad gate, one step later than before. The second scenario: a reason line states a ground the file no longer holds, and only the proofer reading the file catches it. The third: two cases that both call a function with `[]` really are one case, and the report no longer names them.
