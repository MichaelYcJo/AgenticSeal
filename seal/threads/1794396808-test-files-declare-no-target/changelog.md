### Changed

- **`seal layout --pairs` no longer names two calls whose arguments carry no input as a pair (#1489).** A call whose every argument is an empty list, tuple or dict display or `None` is left out of the comparison, as a call with no argument already was. The 66 pairs of `tests/github/test_run_tests.py::Test_main` are gone from the report: they were twelve cases that each call `main([])` under a different monkeypatched world. A call that passes `[]` beside an input is still compared.
- **Each test case stands in the file of what it holds, and each test file that declares no `TARGET` says why on one line (#1489).** The cases of `tests/behaviour/` and `tests/text/` whose subject is one module moved unchanged into that module's file, with their names: 23 into `tests/lib/`, 27 into `tests/skills/`, 5 into `tests/github/` and one into `tests/test_conftest.py`. Nine cases of the two oracles under `tests/` moved into two new module files, `tests/test_commonmark_oracle.py` and `tests/test_gfm_table_oracle.py`. Where the destination bound a module or a helper under another name, a commit before the move rewrote the case to that name. `bin/seal layout --moved` exited 0 for every move. A file whose every case reads one and the same file now declares that file as `TARGET` and runs every census over it. Every other file of the two directories carries one line, `# No TARGET: <the ground>`, where `TARGET` would stand. The ground is that its cases walk the tree, hold one rule across several files, or hold one property across several modules. No script reads the line. Four files left with no case were deleted. A `check:` line, a docstring or a comment that named a moved case or a deleted file names its new home.
- **The test cases #1488 had not read were weighed by its criterion before any of them moved or was filed (#1489).** An assert that pinned wording, or the absence of text a release removed with no rule of that text forbidding it, went. A case left with no assert went with it. A kept assert has a comment above it that names the fact it holds and who reads it.
- **`CONTRIBUTING.md` *The test layout* states where a case stands and why a file declares no `TARGET` (#1489).** A case that calls one module, or runs the script that module is, stands in that module's file. The module may be a shipped one or a module under `tests/` that is not a test file. A case that reads one file and runs no shipped code as its subject belongs to a file that declares that file. Any other case belongs to a file that declares no `TARGET` and gives its ground on the reason line. The files that declare no `TARGET`, wherever they stand, are the tree-wide files that `skills/verify/SKILL.md` runs at every phase boundary. Each pair `bin/seal layout --pairs` prints carries one sentence in its class's docstring, stating the input its two cases differ by. Where the two cases read one input, the sentence says so and names the fact each holds. Every class that holds a printed pair now has that sentence. A module's tests are written anew for a pair only where its class states no input its two cases differ by, so a pair whose cases read one input still counts.

### Removed

- **`seal layout --check --all` (#1489).** The flag refused every file that declares no `TARGET`, and nothing in the tree ran it outside its own cases. `seal layout --check --all` now exits 2 for an unrecognized argument. `seal layout --check` still prints a line for each file that declares no `TARGET` and counts them on its last line.
- **The `check:` line under `docs/releasing/issues-and-milestones.md` *A milestone answers when, and takes three shapes* that named `tests/behaviour/test_a_release_is_sized_by_a_criterion.py` (#1489).** That file's one case held wording alone, and it went with its file.
