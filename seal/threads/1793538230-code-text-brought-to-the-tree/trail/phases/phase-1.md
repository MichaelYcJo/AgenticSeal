**The decisions this phase made, each with its grounds:**

1. **The case asserts each run's exit code beside its streams: 2 for `release_report.py`, 0 for `release_seal.py`, 2 for `rules.py`.** Design S3 asks that the `release_seal.py` run end in `SystemExit(0)`. For the other two, exit 2 is argparse refusing the missing argument inside `main`, so the code shows that each run reached `main` after the loop and did not end earlier. The exit and the streams are one tuple in one assertion, so a failure names both. Judged against: `frame/design.md` *Scope* item 1 and S3.
2. **The comment above each loop names the script's own loader: `meter` in `release_report.py`, `sibling` in `rules.py`, `module` in `release_seal.py`.** Each comment opens with `hooks/lib/console.py#STREAMS` as the owner of the answer, then gives the reason this script spells the loop: a module that will not load ends in `Unreadable` and exit 2 for the first two, and in today's note and an exit of 0 for `release_seal.py`. The last clause repeats the wording of the comment above `release_seal.py#module`. Judged against: `frame/design.md` *Scope* item 1 and the *Grounding* rows on `release_seal.py#module`, `rules.py#sibling` and `release_report.py#meter`.
3. **Each loop spells the three pairs as one literal tuple of `(name, errors)`, the form `hooks/dispatch.py`'s `__main__` loop already uses.** The script cannot read `STREAMS` without importing the module, which is the import plan row 1 rejects. The case reads `STREAMS` at run time, so the copy cannot drift without the case going red. Judged against: `frame/plan.md` *Alternatives considered*, rows 1 and 3.
4. **The case joins `Test_module` in `tests/hooks/test_console.py` and drives the streams with the module's own `cp949_stream` helper, as `Test_to_utf8` does.** `seal layout --check tests/hooks/test_console.py` exited 0, and `seal layout --pairs` names no pair in that file (executed). No case in the group ran any of the three scripts before this one. Judged against: `frame/plan.md` *Alternatives considered*, row 5.
