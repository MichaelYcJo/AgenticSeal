### Changed

- **IADD is the method, and a product only expresses it, so the names fall into three layers (#1658).** The method is IADD, Independent AI-Driven Development. The product is `agentic`, this plugin. The place is `agentory/`, the records root. `docs/method/iadd.md` *The names* opens with that rule and gives each layer's name its one sentence, with rows for the `iadd` block and for the routing question's first answer `agentic`, which shares the product's word and still leaves each item's route to the orchestrator. What is the method's keeps IADD's spelling: the trailer `IADD-Routing:`, the info string `iadd` of a block a script reads fields in, the hook's first line `IADD core from`, the word IADD in the root's marker, and the definition `docs/method/iadd.md`.
- **The plugin is `agentic`, as at 0.39.x.** Its `name`, its marketplace `agenticseal` and the marketplace's entry `agentic`, the prefix `agentic:` of every agent and skill, the slash commands such as `/agentic:update`, and the install spec `agentic@agenticseal` are the names 0.39.4 shipped, so an installed 0.39.x takes this release through `/agentic:update` with no new registration. The display name is `agentic`, where it was `AgenticSeal`, and so are the titles of `README.md`, `README.ko.md` and `CLAUDE.md`; `CONTRIBUTING.md` is *Contributing to agentic*. `.claude-plugin/plugin.json`, `.claude-plugin/marketplace.json` and `README.md` describe it as *The plugin that runs IADD, Independent AI-Driven Development: agents frame, build, review and inspect a change, no agent approves its own work, and the run ends in an inspection bound to a commit.*
- **The command is `agentic`, where it was `seal`.** `bin/agentic` and `bin/agentic.cmd` run `skills/implement/scripts/agentic.py`, each subcommand prints its lines as `agentic <subcommand>: `, and the mutation document is `skills/verify/agentic-mutate.md`. The variables `AGENTIC_GATE_INVOKED_AS`, `AGENTIC_RECORD_DIR` and `AGENTIC_RECORD_KEY`, the pytest recorder `agentic_pytest_record`, the opt-out file `agentic-scratch`, the stamp's directories `agentic-stamp` and `agentic-stamp-refused`, the export's `agentic-last-export.json`, the machine-local maps under `~/.claude/agentic/` and the template's clone `$RUNNER_TEMP/agentic` keep the names 0.39.4 read, so a machine that ran 0.39.4 moves none of them.
- **The records root is `agentory/`, where it was `seal/`.** It stands at the repository's top in shared mode and under the common git directory in local mode, and its `README.md` opens with the marker `# What IADD keeps in agentory/`, written from `templates/setup/agentory-README.md`. *agentory* is formed like *directory* and *repository*: the place where an agent's work is kept. `agentic export` writes `agentory-<repo>-<date>.zip`, a stem built from the root's name, and `agentic import` reads each member under `agentory/`, and refuses a member outside it, so an archive written under another root's name is refused.
