### Changed

- **A pull request body quotes a decision with the question its row answers (#1593).** Where `pr.md` quotes a decision from a table row, the orchestrator quotes the cell of the same row that names what was decided on the line before it, and no sentence joins the two. A `frame/questions.md` row's `Question` cell comes before its `Default until answered` cell, or before its `Status` cell once the row is answered. An *Alternatives considered* row's `Approach` cell comes before its `Verdict` cell. A *Judgments of the run* row's `Judgment` cell comes before its `Grounds` cell. The guidance under `## Judgments of the run` in `templates/records/sdd-plan.md` now asks every row's `Judgment` cell to name the question the judgment answers, then its answer, as "Which prefix the pull request's title takes: `fix:`." does. Before this change, a body could open with an answer whose question stood nowhere above the fold. The table keeps its four columns, so the settle reads every plan as before.
- **The body's *Questions* section copies the whole of `frame/questions.md` below its title.** `agentic pr-body` copied only the lines of the file's table. The judgments the tree answered, which the framer lists above the table, never reached the body, and a table with no row reached it as a header row and a delimiter row. It now copies every line but the title and moves each heading among them one level down, so the heading nests under `## Questions`. A table with no row is replaced by the line "`frame/questions.md` holds a table with no row under its header.". A file with no table line is copied too, and the line "`frame/questions.md` holds no table line." follows the copy. A line above or below the table that holds a closing keyword before an issue number outside a code span is now refused at that line, as a table line was. A pull request body that an earlier release of `agentic pr-body` wrote no longer matches at this section, so the body check refuses it until `agentic pr-body` runs on the body file again.
